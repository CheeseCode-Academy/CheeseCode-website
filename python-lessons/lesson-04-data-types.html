🔢 درس ۴: انواع داده

سطح: مبتدی | زمان مطالعه: ۱۵ دقیقه

🎯 هدف این درس

توی این درس یاد می‌گیری که هر متغیر یه نوع داره و هر نوع برای چیز خاصی استفاده میشه. مثلاً عدد، متن، درست/نادرست و ...

📖 انواع داده در پایتون

هر چیزی که توی پایتون ذخیره می‌کنی، یه نوع داره. مهم‌ترین نوع‌ها این‌ها هستن:

  • str (متن) - برای کلمات و جمله‌ها
  • int (عدد صحیح) - برای اعداد مثل ۱، ۵، ۱۰۰
  • float (عدد اعشاری) - برای اعداد مثل ۳.۱۴، ۲.۵
  • bool (درست/نادرست) - برای True یا False

💻 نوع str (متن)

برای متن از str استفاده می‌کنیم. یعنی هر چیزی که داخل کوتیشن (" ") یا (' ') باشه:

نام = "علی"
پیام = 'سلام به همه!'
متن_توصیفی = "پایتون عالیه!"

💡 نکته: حتی اعداد هم اگر داخل کوتیشن باشن، تبدیل به متن میشن: عدد = "۱۲۳"

💻 نوع int (عدد صحیح)

برای اعداد بدون اعشار از int استفاده می‌کنیم:

سن = 25
تعداد = 10
سال_تولد = 1375

💻 نوع float (عدد اعشاری)

برای اعداد با اعشار از float استفاده می‌کنیم:

قد = 175.5
وزن = 72.3
pi = 3.14

💻 نوع bool (درست/نادرست)

bool فقط دو مقدار داره: True (درست) یا False (نادرست):

آیا_باران_می‌بارد = False
آیا_پایتون_عالی_است = True

💡 نکته: True و False حتماً با حرف بزرگ نوشته میشن!

💻 تشخیص نوع داده با type()

با دستور type() می‌تونی ببینی هر متغیر چه نوعی داره:

نام = "علی"
سن = 25
قد = 175.5
آیا = True

print(type(نام))
print(type(سن))
print(type(قد))
print(type(آیا))
خروجی: 
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>

💻 تبدیل نوع داده

می‌تونی نوع داده رو به هم تبدیل کنی:

# تبدیل متن به عدد
عدد_متنی = "123"
عدد_عددی = int(عدد_متنی)
print(عدد_عددی, type(عدد_عددی))

# تبدیل عدد به متن
عدد = 456
عدد_متنی = str(عدد)
print(عدد_متنی, type(عدد_متنی))

# تبدیل عدد اعشاری به صحیح
pi = 3.14
pi_صحیح = int(pi)  # اعشار رو حذف میکنه
print(pi_صحیح)
خروجی: 
123 <class 'int'>
456 <class 'str'>
3

🧠 اشتباهات رایج

❌ اشتباه: جمع کردن متن با عدد: "۱۰" + ۵

✅ راه‌حل: اول عدد رو به متن تبدیل کن: "۱۰" + str(5) یا عدد رو به int تبدیل کن: int("۱۰") + 5

❌ اشتباه: نوشتن true یا false با حرف کوچک

✅ راه‌حل: همیشه True و False رو با حرف بزرگ بنویس.

💡 نکته‌ی هوشمندانه

از type() برای دیباگ کردن استفاده کن. وقتی مطمئن نیستی که یه متغیر چه نوعی داره، type() رو بزن تا ببینی.

✍️ تمرین‌ها

تمرین ۱ (ساده): چهار متغیر با انواع str، int، float و bool تعریف کن و با type() نوع هر کدوم رو چاپ کن.

تمرین ۲ (متوسط): عدد ۱۵ رو به متن تبدیل کن و با متن "سال" ترکیب کن. (راهنمایی: str())

تمرین ۳ (چالش‌برانگیز): یک عدد اعشاری مثل ۷.۸ رو به عدد صحیح تبدیل کن و بعد دوباره به متن تبدیل کن و چاپ کن.
