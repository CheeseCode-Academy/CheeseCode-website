🔀 درس ۸: شرط‌های چندگانه (elif و else)

سطح: مبتدی | زمان مطالعه: ۱۵ دقیقه

🎯 هدف این درس

توی این درس یاد می‌گیری که چطور با elif و else شرط‌های چندگانه و پیچیده‌تر بنویسی.

📖 ترکیب if، elif و else

ساختار کامل شرط‌ها به این صورته:

  • if - شرط اول
  • elif - شرط دوم (اگر شرط اول نادرست بود)
  • elif - شرط سوم (اگر شرط دوم نادرست بود)
  • ... هر تعداد elif که نیاز باشه
  • else - اگر هیچ کدوم از شرط‌ها درست نبود

💡 یادت باشه: فقط یک if و یک else می‌تونی داشته باشی، ولی تعداد elif محدودیتی نداره.

💻 مثال: سیستم نمره‌دهی

نمره = float(input("نمره خود را (۰ تا ۲۰) وارد کنید: "))

if نمره >= 18:
    print("وضعیت: عالی")
elif نمره >= 16:
    print("وضعیت: خیلی خوب")
elif نمره >= 14:
    print("وضعیت: خوب")
elif نمره >= 12:
    print("وضعیت: قابل قبول")
elif نمره >= 10:
    print("وضعیت: نیاز به تلاش")
else:
    print("وضعیت: مردود")
خروجی (نمونه): 
نمره خود را (۰ تا ۲۰) وارد کنید: 15.5
وضعیت: خوب

💻 مثال: تشخیص فصول سال

ماه = int(input("شماره ماه (۱ تا ۱۲) را وارد کنید: "))

if 1 <= ماه <= 3:
    print("فصل بهار")
elif 4 <= ماه <= 6:
    print("فصل تابستان")
elif 7 <= ماه <= 9:
    print("فصل پاییز")
elif 10 <= ماه <= 12:
    print("فصل زمستان")
else:
    print("شماره ماه نامعتبر است!")
خروجی (نمونه): 
شماره ماه (۱ تا ۱۲) را وارد کنید: 7
فصل پاییز

💻 شرط‌های تو در تو با elif

می‌تونی if رو داخل elif هم بذاری:

سن = int(input("سن خود را وارد کنید: "))

if سن < 0:
    print("سن نامعتبر!")
elif سن < 12:
    if سن < 6:
        print("کودک خردسال")
    else:
        print("کودک دبستانی")
elif سن < 18:
    print("نوجوان")
elif سن < 60:
    print("بزرگسال")
else:
    print("سالمند")
خروجی (نمونه): 
سن خود را وارد کنید: 8
کودک دبستانی

💻 استفاده از عملگرهای منطقی در elif

x = float(input("عدد را وارد کنید: "))

if x > 0 and x < 10:
    print("عدد بین ۰ و ۱۰ است")
elif x >= 10 and x < 20:
    print("عدد بین ۱۰ و ۲۰ است")
elif x >= 20 and x < 30:
    print("عدد بین ۲۰ و ۳۰ است")
else:
    print("عدد خارج از بازه ۰ تا ۳۰ است")
خروجی (نمونه): 
عدد را وارد کنید: 15
عدد بین ۱۰ و ۲۰ است

🧠 اشتباهات رایج

❌ اشتباه: نوشتن elif بدون if اولیه.

✅ راه‌حل: همیشه اول if رو بنویس، بعد elif.

❌ اشتباه: استفاده از else با شرط: else x > 10:

✅ راه‌حل: else هیچ شرطی نداره و برای مواقعی که همه شرط‌ها نادرست بودن استفاده میشه.

❌ اشتباه: نوشتن شرط‌های همپوشانی (overlap):

if x > 5:
    print("بزرگتر از ۵")
elif x > 3:  # این شرط هیچوقت اجرا نمیشه
    print("بزرگتر از ۳")

✅ راه‌حل: شرط‌ها رو به ترتیب از دقیق‌ترین به کلی‌ترین بنویس.

💡 نکته‌ی هوشمندانه

برای چک کردن اینکه یه عدد در یه بازه هست، از زنجیره‌ای کردن عملگرها استفاده کن:

if 10 <= x <= 20:
    print("x بین ۱۰ و ۲۰ است")
# این دقیقاً همون meaning رو داره که:
if x >= 10 and x <= 20:
    print("x بین ۱۰ و ۲۰ است")

این روش خواناتره و کمتر اشتباه میشه.

✍️ تمرین‌ها

تمرین ۱ (ساده): برنامه‌ای بنویس که از کاربر یک عدد بگیره و بگه که "کوچک"، "متوسط" یا "بزرگ" هست. (کوچک: کمتر از ۱۰، متوسط: بین ۱۰ تا ۵۰، بزرگ: بیشتر از ۵۰)

تمرین ۲ (متوسط): برنامه‌ای بنویس که از کاربر سه عدد بگیره و اون‌ها رو به ترتیب صعودی مرتب کنه و چاپ کنه.

تمرین ۳ (چالش‌برانگیز): برنامه‌ای بنویس که از کاربر یک عدد بگیره و بگه که آیا عدد اول هست یا نه. (راهنمایی: عدد اول فقط بر ۱ و خودش بخش‌پذیره)
