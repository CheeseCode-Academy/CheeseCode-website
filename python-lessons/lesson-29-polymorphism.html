🎭 درس ۲۹: چندریختی (Polymorphism)

سطح: متوسط | زمان مطالعه: ۱۸ دقیقه

🎯 هدف این درس

توی این درس با چندریختی (Polymorphism) آشنا میشی که یکی از مهم‌ترین مفاهیم برنامه‌نویسی شی‌گراست.

📖 چندریختی چیست؟

چندریختی (Polymorphism) یعنی یک رابط، چند رفتار. یعنی کلاس‌های مختلف می‌تونن متدهای هم‌نام داشته باشن ولی رفتارهای متفاوتی داشته باشن.

💡 یادت باشه: چندریختی به کدت انعطاف‌پذیری میده و از تکرار کد جلوگیری می‌کنه.

💻 چندریختی با متدهای هم‌نام

class سگ:
    def صدا_بده(self):
        return "هاپ هاپ!"
    
    def حرکت_کن(self):
        return "چهار دست و پا می‌رود"

class گربه:
    def صدا_بده(self):
        return "میو میو!"
    
    def حرکت_کن(self):
        return "چهار دست و پا می‌رود"

class پرنده:
    def صدا_بده(self):
        return "جیک جیک!"
    
    def حرکت_کن(self):
        return "پرواز می‌کند"

# تابع چندریختی
def رفتار_حیوان(حیوان):
    print(حیوان.صدا_بده())
    print(حیوان.حرکت_کن())

رفتار_حیوان(سگ())
رفتار_حیوان(گربه())
رفتار_حیوان(پرنده())

💻 چندریختی با وراثت

class شکل:
    def مساحت(self):
        pass

class مستطیل(شکل):
    def __init__(self, طول, عرض):
        self.طول = طول
        self.عرض = عرض
    
    def مساحت(self):
        return self.طول * self.عرض

class دایره(شکل):
    def __init__(self, شعاع):
        self.شعاع = شعاع
    
    def مساحت(self):
        return 3.14 * self.شعاع ** 2

class مثلث(شکل):
    def __init__(self, قاعده, ارتفاع):
        self.قاعده = قاعده
        self.ارتفاع = ارتفاع
    
    def مساحت(self):
        return 0.5 * self.قاعده * self.ارتفاع

اشکال = [مستطیل(5, 3), دایره(4), مثلث(6, 4)]
for شکل in اشکال:
    print(f"مساحت: {شکل.مساحت():.2f}")
خروجی: 
مساحت: 15.00
مساحت: 50.24
مساحت: 12.00

💻 Duck Typing

در پایتون، "اگر مثل اردک راه بره و مثل اردک صدا بده، پس اردک است":

class اردک:
    def صدا_بده(self):
        return "کواک کواک"
    
    def راه_برو(self):
        return "تاب می‌خورد"

class مرغ:
    def صدا_بده(self):
        return "قُد قُد"
    
    def راه_برو(self):
        return "می‌دود"

class انسان:
    def صدا_بده(self):
        return "سلام!"
    
    def راه_برو(self):
        return "راه می‌رود"

def تست_اردک(چیز):
    print(چیز.صدا_بده())
    print(چیز.راه_برو())

تست_اردک(اردک())
تست_اردک(مرغ())
تست_اردک(انسان())

💡 نکته: Duck Typing یعنی به جای اینکه چک کنی یه شیء از چه کلاسی هست، چک می‌کنی که چه متدهایی داره.

💻 Operator Overloading

چندریختی با عملگرها:

class عدد_با_واحد:
    def __init__(self, مقدار, واحد):
        self.مقدار = مقدار
        self.واحد = واحد
    
    def __add__(self, دیگر):
        if self.واحد != دیگر.واحد:
            raise ValueError("واحدها متفاوت هستند!")
        return عدد_با_واحد(self.مقدار + دیگر.مقدار, self.واحد)
    
    def __str__(self):
        return f"{self.مقدار} {self.واحد}"

وزن۱ = عدد_با_واحد(5, "kg")
وزن۲ = عدد_با_واحد(3, "kg")
وزن۳ = وزن۱ + وزن۲
print(وزن۳)  # 8 kg

💻 ABC (Abstract Base Classes)

برای强制执行 چندریختی:

from abc import ABC, abstractmethod

class شکل(ABC):
    @abstractmethod
    def مساحت(self):
        pass

class مستطیل(شکل):
    def __init__(self, طول, عرض):
        self.طول = طول
        self.عرض = عرض
    
    def مساحت(self):
        return self.طول * self.عرض

❌ اشتباه: فراموش کردن @abstractmethod در کلاس‌های انتزاعی

💡 نکته‌ی هوشمندانه

از functools.singledispatch برای چندریختی با توابع استفاده کن:

from functools import singledispatch

@singledispatch
def پردازش(obj):
    return f"نوع نامشخص: {obj}"

@پردازش.register(int)
def _(obj):
    return f"عدد: {obj}"

@پردازش.register(str)
def _(obj):
    return f"متن: {obj}"

print(پردازش(10))   # عدد: 10
print(پردازش("سلام")) # متن: سلام
print(پردازش(3.14)) # نوع نامشخص: 3.14

✍️ تمرین‌ها

تمرین ۱ (ساده): سه کلاس با متد صدا_بده بساز و با یک حلقه همه رو صدا بزن.

تمرین ۲ (متوسط): کلاس وسیله_نقلیه بساز و کلاس‌های ماشین و دوچرخه ازش ارث ببرن و متد حرکت_کن رو بازنویسی کنن.

تمرین ۳ (چالش‌برانگیز): کلاس انتزاعی محاسبه_گر بساز با متد محاسبه و دو کلاس جمع_کننده و ضرب_کننده که اون رو پیاده‌سازی کنن.
