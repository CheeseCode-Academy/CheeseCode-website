📦 درس ۱۳: تاپل‌ها (Tuples)

سطح: مبتدی | زمان مطالعه: ۱۴ دقیقه

🎯 هدف این درس

توی این درس با تاپل‌ها آشنا میشی. تاپل‌ها مثل لیست‌ها هستن با این تفاوت که غیرقابل تغییر هستن.

📖 تاپل چیست؟

تاپل (Tuple) یه ساختار داده مثل لیست هست، با این تفاوت که غیرقابل تغییر (immutable) هست. یعنی بعد از ساخته شدن، نمی‌تونی اعضاش رو عوض کنی، حذف کنی یا اضافه کنی.

تاپل‌ها برای زمانی که می‌خوای یه سری داده رو ثابت نگه داری، عالی هستن.

💡 یادت باشه: تاپل‌ها با پرانتز ( ) تعریف میشن و اعضاشون با کاما (,) از هم جدا میشن.

💻 تعریف تاپل

# تاپل خالی
تاپل_خالی = ()

# تاپل از اعداد
اعداد = (1, 2, 3, 4, 5)

# تاپل از متن‌ها
میوه‌ها = ("سیب", "موز", "پرتقال")

# تاپل از انواع مختلف
مختلط = ("علی", 25, 175.5, True)

# تاپل با یک عضو (به کاما توجه کن!)
یک_عضو = ("سلام",)

print(میوه‌ها)
خروجی: 
('سیب', 'موز', 'پرتقال')

💡 نکته: برای تاپل یک عضوی، حتماً بعد از عضو کاما بذار، وگرنه پایتون اون رو تاپل حساب نمی‌کنه.

💻 دسترسی به اعضای تاپل

دسترسی به اعضای تاپل دقیقاً مثل لیست هست:

میوه‌ها = ("سیب", "موز", "پرتقال", "انگور", "هندوانه")

print(میوه‌ها[0])  # اولین عضو
print(میوه‌ها[2])  # سومین عضو
print(میوه‌ها[-1]) # آخرین عضو
print(میوه‌ها[1:4]) # برش
خروجی: 
سیب
پرتقال
هندوانه
('موز', 'پرتقال', 'انگور')

💻 تفاوت تاپل و لیست

# لیست قابل تغییره
لیست = [1, 2, 3]
لیست[0] = 100
print(لیست)  # [100, 2, 3]

# تاپل غیرقابل تغییره
تاپل = (1, 2, 3)
# تاپل[0] = 100  # این خط ارور میده!
# TypeError: 'tuple' object does not support item assignment

💻 متدهای تاپل

تاپل‌ها متدهای محدودی دارن چون غیرقابل تغییر هستن:

تاپل = (1, 2, 3, 2, 4, 2, 5)

# count() - تعداد تکرار
print(تاپل.count(2))

# index() - پیدا کردن ایندکس
print(تاپل.index(4))

# len() - تعداد اعضا
print(len(تاپل))

# in - بررسی عضویت
print(3 in تاپل)
print(7 in تاپل)
خروجی: 
3
4
7
True
False

💻 تبدیل لیست به تاپل و برعکس

# لیست به تاپل
لیست = [1, 2, 3, 4]
تاپل = tuple(لیست)
print(تاپل)

# تاپل به لیست
تاپل = (5, 6, 7, 8)
لیست = list(تاپل)
print(لیست)
خروجی: 
(1, 2, 3, 4)
[5, 6, 7, 8]

💻 تاپل و حلقه for

میوه‌ها = ("سیب", "موز", "پرتقال", "انگور")

for میوه in میوه‌ها:
    print(میوه)
خروجی: 
سیب
موز
پرتقال
انگور

💻 unpacking در تاپل

می‌تونی اعضای تاپل رو به متغیرهای جداگانه اختصاص بدی:

مختصات = (10, 20, 30)
x, y, z = مختصات
print("x:", x, "y:", y, "z:", z)

# استفاده در حلقه
نقاط = [(1, 2), (3, 4), (5, 6)]
for x, y in نقاط:
    print("x:", x, "y:", y)
خروجی: 
x: 10 y: 20 z: 30
x: 1 y: 2
x: 3 y: 4
x: 5 y: 6

💻 تاپل به عنوان کلید دیکشنری

چون تاپل‌ها غیرقابل تغییر هستن، می‌تونن کلید دیکشنری بشن:

# لیست نمی‌تونه کلید باشه
# دیکشنری = {[1, 2]: "value"}  # ارور!

# تاپل می‌تونه کلید باشه
دیکشنری = {(1, 2): "نقطه اول", (3, 4): "نقطه دوم"}
print(دیکشنری[(1, 2)])
خروجی: 
نقطه اول

🧠 اشتباهات رایج

❌ اشتباه: سعی در تغییر تاپل: تاپل[0] = 10

✅ راه‌حل: اگر نیاز به تغییر داری، اول به لیست تبدیل کن، تغییر بده و دوباره به تاپل برگردون.

❌ اشتباه: فراموش کردن کاما برای تاپل یک عضوی: تاپل = ("سلام") که این یه رشته‌ست، نه تاپل!

✅ راه‌حل: حتماً کاما بذار: تاپل = ("سلام",)

💡 نکته‌ی هوشمندانه

از تاپل برای برگرداندن چند مقدار از تابع استفاده کن:

def آمار(اعداد):
    return (min(اعداد), max(اعداد), sum(اعداد)/len(اعداد))

لیست = [10, 20, 30, 40, 50]
کوچک, بزرگ, میانگین = آمار(لیست)
print(f"کوچک: {کوچک}, بزرگ: {بزرگ}, میانگین: {میانگین}")

این خیلی کاربردی‌تر از برگردوندن لیسته.

✍️ تمرین‌ها

تمرین ۱ (ساده): یک تاپل از ۵ شهر favorite خودت بساز و با حلقه for چاپ کن.

تمرین ۲ (متوسط): یک تاپل از ۳ رنگ بساز و با unpacking هر کدوم رو توی متغیر جداگانه بریز.

تمرین ۳ (چالش‌برانگیز): یک تاپل از اعداد بساز و جمع همه‌شون رو بدون استفاده از sum() محاسبه کن.
