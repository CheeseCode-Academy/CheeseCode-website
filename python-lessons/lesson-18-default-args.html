سطح: مبتدی | زمان مطالعه: ۱۵ دقیقه

🎯 هدف این درس

توی این درس با آرگومان‌های پیش‌فرض آشنا میشی و یاد می‌گیری چطور توابع انعطاف‌پذیرتری بنویسی.

📖 آرگومان پیش‌فرض چیست؟

آرگومان پیش‌فرض (Default Argument) به پارامترهایی گفته میشه که مقدار پیش‌فرض دارن. اگر موقع صدا زدن تابع مقدار ندی، از مقدار پیش‌فرض استفاده میشه.

💡 یادت باشه: پارامترهای پیش‌فرض باید بعد از پارامترهای اجباری بیان.

💻 مثال ساده

def سلام(نام, رسمی=False):
    if رسمی:
        print(f"جناب {نام}، خوش آمدید!")
    else:
        print(f"سلام {نام}!")

سلام("علی")           # استفاده از مقدار پیش‌فرض (رسمی=False)
سلام("زهرا", True)   # مقدار جدید
خروجی: 
سلام علی!
جناب زهرا، خوش آمدید!

💻 چند پارامتر پیش‌فرض

def ثبت_نام(نام, سن=0, شهر="نامشخص", رشته="نامشخص"):

💻 استفاده از کلیدواژه‌ها

می‌تونی فقط بعضی از پارامترها رو مقدار بدی:

def اطلاعات(نام, سن=0, شهر="نامشخص", رشته="نامشخص"):
    print(f"{نام}، {سن} سال، {شهر}، {رشته}")

اطلاعات("علی")
اطلاعات("زهرا", شهر="تهران")  # فقط شهر رو مقدار می‌دیم
اطلاعات("رضا", رشته="برنامه‌نویسی")
خروجی: 
علی، 0 سال، نامشخص، نامشخص
زهرا، 0 سال، تهران، نامشخص
رضا، 0 سال، نامشخص، برنامه‌نویسی

💻 قانون مهم: ترتیب پارامترها

پارامترهای اجباری باید قبل از پارامترهای اختیاری بیان:

# درسته
def تابع_درست(a, b, c=10, d=20):
    print(a, b, c, d)

💻 مقدار پیش‌فرض متغیر

مقدار پیش‌فرض می‌تونه هر چیزی باشه:

def تابع(نام, اعداد=[]):
    اعداد.append(نام)
    return اعداد

print(تابع("علی"))
print(تابع("زهرا"))
خروجی: 
['علی']
['علی', 'زهرا']

⚠️ هشدار مهم: این کار خطرناکه! چون لیست بین دفعات مختلف به‌اشتراک گذاشته میشه. بهتره از None استفاده کنی.

💻 روش امن برای مقدار پیش‌فرض متغیر

def تابع_امن(نام, اعداد=None):
    if اعداد is None:
        اعداد = []
    اعداد.append(نام)
    return اعداد

print(تابع_امن("علی"))
print(تابع_امن("زهرا"))
خروجی: 
['علی']
['زهرا']

💻 استفاده از توابع به عنوان پیش‌فرض

def زمان_حال():
    from datetime import datetime
    return datetime.now()

def لاگ(پیام, زمان=زمان_حال()):
    print(f"[{زمان}] {پیام}")

لاگ("برنامه شروع شد")
لاگ("کاربر وارد شد")
خروجی (نمونه): 
[2026-07-21 14:30:25.123456] برنامه شروع شد
[2026-07-21 14:30:25.123456] کاربر وارد شد

🧠 اشتباهات رایج

❌ اشتباه: قرار دادن پارامتر اختیاری قبل از اجباری:

def غلط(a=10, b):  # ارور!
    return a + b

✅ راه‌حل: همیشه پارامترهای اجباری رو اول بذار:

def درست(b, a=10):
    return a + b

❌ اشتباه: استفاده از لیست به عنوان مقدار پیش‌فرض:

def تابع(لیست=[]):  # خطرناک!

✅ راه‌حل: از None استفاده کن:

def تابع(لیست=None):
    if لیست is None:
        لیست = []

💡 نکته‌ی هوشمندانه

از پارامترهای پیش‌فرض برای ساده‌سازی رابط کاربری تابع استفاده کن:

def جستجو(عبارت, حساس_به_حروف=False, دقیق=False):
    # کد جستجو
    pass

# کاربر می‌تونه به سادگی ازش استفاده کنه
جستجو("python")
جستجو("Python", حساس_به_حروف=True)

✍️ تمرین‌ها

تمرین ۱ (ساده): تابعی بنویس که نام و سن رو بگیره، با سن پیش‌فرض ۱۸.

تمرین ۲ (متوسط): تابعی بنویس که متن و تعداد تکرار رو بگیره و متن رو به تعداد مشخص چاپ کنه (تعداد پیش‌فرض ۱).

تمرین ۳ (چالش‌برانگیز): تابعی بنویس که لیستی از اعداد و یک مقدار پیش‌فرض برای mode داشته باشه که مشخص کنه جمع یا ضرب انجام بده.
