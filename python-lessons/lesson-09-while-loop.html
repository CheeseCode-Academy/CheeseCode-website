🔄 درس ۹: حلقه while

سطح: مبتدی | زمان مطالعه: ۱۶ دقیقه

🎯 هدف این درس

توی این درس یاد می‌گیری که چطور با حلقه while یه کار رو تکرار کنی تا وقتی که یه شرط برقراره.

📖 حلقه while چیست؟

while به برنامه می‌گه "تا وقتی که این شرط درسته، این کار رو تکرار کن".

فرض کن به یه ربات می‌گی: "تا وقتی که غذا تموم نشده، به خوردن ادامه بده". این دقیقاً همون کاریه که while انجام میده.

💡 یادت باشه: حلقه while تا وقتی که شرطش True باشه، ادامه پیدا می‌کنه. وقتی شرط بشه False، حلقه تموم میشه.

💻 ساختار while

شمارنده = 1

while شمارنده <= 5:
    print("شمارنده:", شمارنده)
    شمارنده = شمارنده + 1
خروجی: 
شمارنده: 1
شمارنده: 2
شمارنده: 3
شمارنده: 4
شمارنده: 5

💡 نکته: متغیر شمارنده رو هر بار ۱ واحد زیاد می‌کنیم تا حلقه بعد از ۵ بار تکرار تموم بشه.

💻 while با ورودی کاربر

پاسخ = ""

while پاسخ != "بله":
    پاسخ = input("آیا می‌خواهید ادامه دهید؟ (بله/خیر): ")
    if پاسخ == "خیر":
        print("برنامه خاتمه یافت")
        break
    elif پاسخ == "بله":
        print("ادامه می‌دهیم...")
    else:
        print("لطفاً فقط بله یا خیر وارد کنید")
خروجی (نمونه): 
آیا می‌خواهید ادامه دهید؟ (بله/خیر): شاید
لطفاً فقط بله یا خیر وارد کنید
آیا می‌خواهید ادامه دهید؟ (بله/خیر): بله
ادامه می‌دهیم...

💻 while با break

break باعث میشه که حلقه همون لحظه متوقف بشه:

i = 1

while True:  # حلقه بی‌نهایت!
    print(i)
    i += 1
    if i > 5:
        break  # وقتی i به ۶ رسید، حلقه رو متوقف کن

print("حلقه تمام شد")
خروجی: 
1
2
3
4
5
حلقه تمام شد

💡 نکته: while True یه حلقه‌ی بی‌نهایت می‌سازه. با break می‌تونی ازش خارج بشی.

💻 while با continue

continue باعث میشه که بقیه‌ی کدهای حلقه رد بشن و بره به تکرار بعدی:

i = 0

while i < 10:
    i += 1
    if i % 2 == 0:
        continue  # اعداد زوج رو چاپ نکن
    print(i)
خروجی: 
1
3
5
7
9

💻 while با else

بخش else وقتی اجرا میشه که حلقه به طور طبیعی تموم بشه (نه با break):

i = 1

while i <= 3:
    print(i)
    i += 1
else:
    print("حلقه به طور کامل اجرا شد")
خروجی: 
1
2
3
حلقه به طور کامل اجرا شد
i = 1

while i <= 3:
    print(i)
    if i == 2:
        break
    i += 1
else:
    print("این قسمت اجرا نمیشه")
خروجی: 
1
2

🧠 اشتباهات رایج

❌ اشتباه: فراموش کردن افزایش متغیر شرط:

i = 1
while i <= 5:
    print(i)
    # i = i + 1 رو فراموش کردی!

✅ راه‌حل: همیشه متغیر شرط رو تغییر بده تا حلقه بی‌نهایت نشه:

i = 1
while i <= 5:
    print(i)
    i += 1

❌ اشتباه: ایجاد حلقه‌ی بی‌نهایت با شرط همیشه درست:

while True:
    print("بی‌نهایت!")

✅ راه‌حل: یا شرط رو درست بنویس یا از break برای خروج استفاده کن.

💡 نکته‌ی هوشمندانه

از while True با break برای ساخت منوهای تعاملی استفاده کن:

while True:
    print("1. شروع")
    print("2. راهنما")
    print("3. خروج")
    انتخاب = input("انتخاب خود را وارد کنید: ")
    
    if انتخاب == "3":
        print("خروج از برنامه")
        break
    elif انتخاب == "1":
        print("شروع برنامه...")
    elif انتخاب == "2":
        print("راهنما...")
    else:
        print("انتخاب نامعتبر!")

✍️ تمرین‌ها

تمرین ۱ (ساده): با while اعداد ۱ تا ۱۰ رو چاپ کن.

تمرین ۲ (متوسط): برنامه‌ای بنویس که از کاربر عددی بگیره و با while تمام اعداد از ۱ تا اون عدد رو چاپ کنه.

تمرین ۳ (چالش‌برانگیز): برنامه‌ای بنویس که از کاربر عددی بگیره و فاکتوریل اون عدد رو با while محاسبه کنه. (راهنمایی: فاکتوریل ۵ = ۱×۲×۳×۴×۵)
