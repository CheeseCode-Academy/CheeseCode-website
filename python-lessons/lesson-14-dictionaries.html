📖 درس ۱۴: دیکشنری‌ها (Dictionaries)

سطح: مبتدی | زمان مطالعه: ۲۰ دقیقه

🎯 هدف این درس

توی این درس با دیکشنری‌ها آشنا میشی. دیکشنری‌ها مثل یه دفترچه تلفن هستن که با یه کلید (اسم) می‌تونی به مقدار (شماره تلفن) دسترسی پیدا کنی.

📖 دیکشنری چیست؟

دیکشنری (Dictionary) یه ساختار داده هست که داده‌ها رو به صورت کلید-مقدار (key-value) ذخیره می‌کنه. هر کلید یه مقدار داره و با اون کلید می‌تونی به مقدار دسترسی پیدا کنی.

فرض کن دیکشنری مثل یه دفترچه تلفن هست: اسم (کلید) و شماره (مقدار).

💡 یادت باشه: دیکشنری‌ها با آکولاد { } تعریف میشن و هر کلید-مقدار با دونقطه (:) از هم جدا میشن.

💻 تعریف دیکشنری

# دیکشنری خالی
دیکشنری_خالی = {}

# دیکشنری از افراد
افراد = {
    "علی": 25,
    "زهرا": 30,
    "رضا": 22
}

# دیکشنری با انواع مختلف
فرد = {
    "نام": "علی",
    "سن": 25,
    "قد": 175.5,
    "مجرد": True,
    "علاقه‌مندی‌ها": ["برنامه‌نویسی", "ورزش", "موسیقی"]
}

print(افراد)
print(فرد)
خروجی: 
{'علی': 25, 'زهرا': 30, 'رضا': 22}
{'نام': 'علی', 'سن': 25, 'قد': 175.5, 'مجرد': True, 'علاقه‌مندی‌ها': ['برنامه‌نویسی', 'ورزش', 'موسیقی']}

💻 دسترسی به مقادیر دیکشنری

فرد = {
    "نام": "علی",
    "سن": 25,
    "شهر": "تهران"
}

# روش اول: با کروشه
print(فرد["نام"])
print(فرد["سن"])

# روش دوم: با get() (امن‌تر)
print(فرد.get("شهر"))
print(فرد.get("کشور", "نامشخص"))  # اگر کلید نباشه، مقدار پیش‌فرض
خروجی: 
علی
25
تهران
نامشخص

💡 نکته: تفاوت [] و get(): اگر کلید نباشه، [] ارور میده ولی get() None یا مقدار پیش‌فرض برمی‌گردونه.

💻 تغییر و اضافه کردن

فرد = {"نام": "علی", "سن": 25}

# تغییر مقدار
فرد["سن"] = 26
print(فرد)

# اضافه کردن کلید جدید
فرد["شهر"] = "تهران"
فرد["علاقه‌مندی"] = "برنامه‌نویسی"
print(فرد)
خروجی: 
{'نام': 'علی', 'سن': 26}
{'نام': 'علی', 'سن': 26, 'شهر': 'تهران', 'علاقه‌مندی': 'برنامه‌نویسی'}

💻 حذف از دیکشنری

فرد = {"نام": "علی", "سن": 25, "شهر": "تهران", "علاقه": "برنامه‌نویسی"}

# حذف با pop()
شهر = فرد.pop("شهر")
print("شهر حذف شد:", شهر)
print(فرد)

# حذف با del
del فرد["علاقه"]
print(فرد)

# حذف آخرین عضو (popitem())
آخرین = فرد.popitem()
print("آخرین عضو:", آخرین)
print(فرد)

# پاک کردن کل دیکشنری
فرد.clear()
print(فرد)
خروجی: 
شهر حذف شد: تهران
{'نام': 'علی', 'سن': 25, 'علاقه': 'برنامه‌نویسی'}
{'نام': 'علی', 'سن': 25}
آخرین عضو: ('سن', 25)
{'نام': 'علی'}
{}

💻 حلقه for روی دیکشنری

فرد = {"نام": "علی", "سن": 25, "شهر": "تهران"}

# فقط کلیدها
for کلید in فرد:
    print(کلید)

print("---")

# کلید و مقدار با items()
for کلید, مقدار in فرد.items():
    print(کلید, ":", مقدار)
خروجی: 
نام
سن
شهر
---
نام : علی
سن : 25
شهر : تهران

💻 متدهای دیکشنری

فرد = {"نام": "علی", "سن": 25, "شهر": "تهران"}

# keys() - همه کلیدها
print("کلیدها:", فرد.keys())

# values() - همه مقادیر
print("مقادیر:", فرد.values())

# items() - همه کلید-مقدارها
print("آیتم‌ها:", فرد.items())

# get() - دریافت مقدار
print("سن:", فرد.get("سن"))

# update() - به‌روزرسانی
فرد.update({"سن": 26, "علاقه": "برنامه‌نویسی"})
print("بعد از update:", فرد)
خروجی: 
کلیدها: dict_keys(['نام', 'سن', 'شهر'])
مقادیر: dict_values(['علی', 25, 'تهران'])
آیتم‌ها: dict_items([('نام', 'علی'), ('سن', 25), ('شهر', 'تهران')])
سن: 25
بعد از update: {'نام': 'علی', 'سن': 26, 'شهر': 'تهران', 'علاقه': 'برنامه‌نویسی'}

💻 دیکشنری تو در تو

افراد = {
    "علی": {
        "سن": 25,
        "شهر": "تهران",
        "علاقه": ["برنامه‌نویسی", "ورزش"]
    },
    "زهرا": {
        "سن": 30,
        "شهر": "اصفهان",
        "علاقه": ["موسیقی", "کتاب"]
    }
}

# دسترسی به اطلاعات
print("سن علی:", افراد["علی"]["سن"])
print("علاقه‌های زهرا:", افراد["زهرا"]["علاقه"])

# حلقه روی دیکشنری تو در تو
for نام, اطلاعات in افراد.items():
    print(f"\n{نام}:")
    for کلید, مقدار in اطلاعات.items():
        print(f"  {کلید}: {مقدار}")
خروجی: 
سن علی: 25
علاقه‌های زهرا: ['موسیقی', 'کتاب']

علی:
  سن: 25
  شهر: تهران
  علاقه: ['برنامه‌نویسی', 'ورزش']

زهرا:
  سن: 30
  شهر: اصفهان
  علاقه: ['موسیقی', 'کتاب']

🧠 اشتباهات رایج

❌ اشتباه: دسترسی به کلیدی که وجود نداره با []: فرد["کشور"]

✅ راه‌حل: از get() استفاده کن یا اول با in چک کن.

❌ اشتباه: استفاده از لیست به عنوان کلید: {[1, 2]: "value"}

✅ راه‌حل: کلیدها باید غیرقابل تغییر باشن. از تاپل به جای لیست استفاده کن.

❌ اشتباه: فراموش کردن () در متدها: فرد.keys

✅ راه‌حل: همیشه پرانتز بذار: فرد.keys()

💡 نکته‌ی هوشمندانه

از dict() برای ساخت دیکشنری از لیست تاپل‌ها استفاده کن:

لیست_تاپل‌ها = [("نام", "علی"), ("سن", 25), ("شهر", "تهران")]
فرد = dict(لیست_تاپل‌ها)
print(فرد)  # {'نام': 'علی', 'سن': 25, 'شهر': 'تهران'}

✍️ تمرین‌ها

تمرین ۱ (ساده): یک دیکشنری از اطلاعات خودت بساز (نام، سن، شهر، رشته تحصیلی) و چاپ کن.

تمرین ۲ (متوسط): دیکشنری از ۳ نفر با اطلاعات (نام، سن، شهر) بساز و با حلقه همه رو چاپ کن.

تمرین ۳ (چالش‌برانگیز): برنامه‌ای بنویس که از کاربر اطلاعات افراد رو بگیره و توی دیکشنری ذخیره کنه. کاربر می‌تونه افراد جدید اضافه کنه یا اطلاعات افراد موجود رو ببینه.
