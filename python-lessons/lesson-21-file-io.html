📖 کار با فایل در پایتون

پایتون بهت اجازه میده با فایل‌های مختلف کار کنی: متن، CSV، JSON، تصویر و ...

کار با فایل معمولاً ۳ مرحله داره:

  1. باز کردن فایل با open()
  2. خواندن یا نوشتن با متدهای مختلف
  3. بستن فایل با close()

💡 یادت باشه: همیشه بعد از کار با فایل، اون رو ببند تا اطلاعات ذخیره بشن و حافظه آزاد بشه.

💻 حالت‌های باز کردن فایل

  • 'r' - خواندن (پیش‌فرض)
  • 'w' - نوشتن (محتوای قبلی پاک میشه)
  • 'a' - افزودن به انتهای فایل
  • 'x' - ایجاد فایل جدید (اگر وجود داشته باشه ارور میده)
  • 'r+' - خواندن و نوشتن

💻 نوشتن در فایل

# نوشتن در فایل (محتوای قبلی پاک میشه)
فایل = open("test.txt", "w")
فایل.write("سلام دنیا!\n")
فایل.write("این خط دوم هست.\n")
فایل.close()

# افزودن به انتهای فایل
فایل = open("test.txt", "a")
فایل.write("این خط به انتها اضافه شد.\n")
فایل.close()

محتوای فایل test.txt:

خروجی (محتوای فایل): 
سلام دنیا!
این خط دوم هست.
این خط به انتها اضافه شد.

💻 خواندن از فایل

# روش‌های مختلف خواندن
فایل = open("test.txt", "r")

# خواندن کل فایل
کل_محتوا = فایل.read()
print("کل محتوا:\n", کل_محتوا)

# برگرد به ابتدای فایل
فایل.seek(0)

# خواندن خط به خط
خطوط = فایل.readlines()
print("خطوط:", خطوط)

# برگرد به ابتدای فایل
فایل.seek(0)

# خواندن با حلقه
for خط in فایل:
    print("خط:", خط.strip())

فایل.close()
خروجی: 
کل محتوا:
 سلام دنیا!
این خط دوم هست.
این خط به انتها اضافه شد.

خطوط: ['سلام دنیا!\n', 'این خط دوم هست.\n', 'این خط به انتها اضافه شد.\n']
خط: سلام دنیا!
خط: این خط دوم هست.
خط: این خط به انتها اضافه شد.

💻 استفاده از with (روش پیشنهادی)

with به‌طور خودکار فایل رو می‌بنده:

# نوشتن با with
with open("data.txt", "w") as فایل:
    فایل.write("این یک خط است.\n")
    فایل.write("این خط دوم است.\n")
# فایل به‌طور خودکار بسته میشه

# خواندن با with
with open("data.txt", "r") as فایل:
    محتوا = فایل.read()
    print(محتوا)
# فایل به‌طور خودکار بسته میشه
خروجی: 
این یک خط است.
این خط دوم است.

💡 نکته: استفاده از with امن‌تر و خواناتر هست و نیازی به close() نداره.

💻 خواندن فایل‌های CSV

import csv

# نوشتن CSV
with open("افراد.csv", "w", newline="") as فایل:
    نویسنده = csv.writer(فایل)
    نویسنده.writerow(["نام", "سن", "شهر"])
    نویسنده.writerow(["علی", "25", "تهران"])
    نویسنده.writerow(["زهرا", "30", "اصفهان"])

# خواندن CSV
with open("افراد.csv", "r") as فایل:
    خواننده = csv.reader(فایل)
    for ردیف in خواننده:
        print(ردیف)
خروجی: 
['نام', 'سن', 'شهر']
['علی', '25', 'تهران']
['زهرا', '30', 'اصفهان']

💻 بررسی وجود فایل

import os

if os.path.exists("test.txt"):
    print("فایل وجود داره")
    with open("test.txt", "r") as فایل:
        print(فایل.read())
else:
    print("فایل وجود نداره")

💻 حذف فایل

import os

if os.path.exists("test.txt"):
    os.remove("test.txt")
    print("فایل حذف شد")
else:
    print("فایل وجود نداره")

🧠 اشتباهات رایج

❌ اشتباه: فراموش کردن close() فایل

✅ راه‌حل: از with استفاده کن که خودکار می‌بنده.

❌ اشتباه: باز کردن فایل در حالت 'w' و از دست دادن اطلاعات قبلی

✅ راه‌حل: برای اضافه کردن از 'a' استفاده کن.

❌ اشتباه: خواندن فایلی که وجود نداره

✅ راه‌حل: اول با os.path.exists() چک کن.

💡 نکته‌ی هوشمندانه

از with برای کار با چند فایل همزمان استفاده کن:

with open("ورودی.txt", "r") as ورودی, open("خروجی.txt", "w") as خروجی:
    for خط in ورودی:
        خروجی.write(خط.upper())  # تبدیل به حروف بزرگ

✍️ تمرین‌ها

تمرین ۱ (ساده): یه فایل به اسم name.txt بساز و اسم خودت رو توش بنویس.

تمرین ۲ (متوسط): فایل name.txt رو بخون و محتواش رو چاپ کن.

تمرین ۳ (چالش‌برانگیز): برنامه‌ای بنویس که از کاربر ۵ اسم بگیره، توی فایل names.txt ذخیره کنه و بعد دوباره بخونه و چاپ کنه.
