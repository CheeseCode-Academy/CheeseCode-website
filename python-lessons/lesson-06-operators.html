➕ درس ۶: عملگرها

سطح: مبتدی | زمان مطالعه: ۱۸ دقیقه

🎯 هدف این درس

توی این درس با عملگرها آشنا میشی. عملگرها ابزارهایی هستن که با اون‌ها می‌تونی محاسبات ریاضی، مقایسه‌ها و کارهای منطقی انجام بدی.

📖 عملگرهای ریاضی

این عملگرها برای انجام محاسبات عددی استفاده میشن:

  • + (جمع)
  • - (تفریق)
  • * (ضرب)
  • / (تقسیم - نتیجه اعشاری)
  • // (تقسیم صحیح - فقط جزء صحیح)
  • % (باقیمانده تقسیم)
  • ** (توان)

💻 مثال‌های عملگرهای ریاضی

a = 10
b = 3

print("جمع:", a + b)
print("تفریق:", a - b)
print("ضرب:", a * b)
print("تقسیم:", a / b)
print("تقسیم صحیح:", a // b)
print("باقیمانده:", a % b)
print("توان:", a ** b)
خروجی: 
جمع: 13
تفریق: 7
ضرب: 30
تقسیم: 3.3333333333333335
تقسیم صحیح: 3
باقیمانده: 1
توان: 1000

💻 عملگرهای مقایسه‌ای

این عملگرها برای مقایسه دو مقدار استفاده میشن و نتیجه‌شون True یا False هست:

  • == (برابر)
  • != (نامساوی)
  • > (بزرگتر)
  • < (کوچکتر)
  • >= (بزرگتر یا مساوی)
  • <= (کوچکتر یا مساوی)
x = 10
y = 20

print(x == y)   # False
print(x != y)   # True
print(x > y)    # False
print(x < y)    # True
print(x >= 10)  # True
print(y <= 15)  # False

False

False

💻 عملگرهای منطقی

این عملگرها برای ترکیب شرط‌ها استفاده میشن:

  • and (و) - هر دو شرط درست باشن
  • or (یا) - حداقل یکی از شرط‌ها درست باشه
  • not (نقیض) - برعکس کردن شرط
سن = 25
گواهینامه = True

print(سن >= 18 and گواهینامه == True)  # True
print(سن >= 18 or گواهینامه == False)  # True
print(not (سن < 18))                   # True
خروجی: 
True
True
True

💻 عملگرهای انتساب

این عملگرها برای مقداردهی و تغییر مقدار متغیرها استفاده میشن:

x = 10        # انتساب ساده
x += 5        # یعنی x = x + 5
print(x)      # 15

x -= 3        # یعنی x = x - 3
print(x)      # 12

x *= 2        # یعنی x = x * 2
print(x)      # 24

x /= 4        # یعنی x = x / 4
print(x)      # 6.0

x //= 2       # یعنی x = x // 2
print(x)      # 3.0

x %= 3        # یعنی x = x % 3
print(x)      # 0.0
خروجی: 
15
12
24
6.0
3.0
0.0

💻 عملگرهای هویتی

is و is not برای مقایسه اینکه آیا دو متغیر به یک شیء اشاره می‌کنن: 

a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a == b)    # True (مقدارشون برابر)
print(a is b)    # False (شیء متفاوت)
print(a is c)    # True (همون شیء)
خروجی: 
True
False
True

🧠 اشتباهات رایج

❌ اشتباه: استفاده از = به جای == برای مقایسه: if x = 5:

✅ راه‌حل: برای مقایسه از == استفاده کن: if x == 5:

❌ اشتباه: تقسیم دو عدد صحیح با / که نتیجه اعشاری میده ولی انتظار عدد صحیح داریم.

✅ راه‌حل: از // برای تقسیم صحیح استفاده کن.

💡 نکته‌ی هوشمندانه

از عملگر % (باقیمانده) برای تشخیص زوج یا فرد بودن استفاده کن:

عدد = 7
if عدد % 2 == 0:
    print("زوج")
else:
    print("فرد")

✍️ تمرین‌ها

تمرین ۱ (ساده): برنامه‌ای بنویس که دو عدد از کاربر بگیره و مجموع، تفریق، ضرب و تقسیمشون رو چاپ کنه.

تمرین ۲ (متوسط): برنامه‌ای بنویس که از کاربر یک عدد بگیره و بگه زوجه یا فرد؟

تمرین ۳ (چالش‌برانگیز): برنامه‌ای بنویس که سه عدد از کاربر بگیره و بزرگترینشون رو پیدا کنه و چاپ کنه. (بدون استفاده از تابع max)
