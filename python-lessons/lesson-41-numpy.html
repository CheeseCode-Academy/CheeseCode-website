با NumPy آشنا بشی، مهم‌ترین کتابخانه برای محاسبات عددی و آرایه‌ها در پایتون.

📖 NumPy چیست؟

NumPy (Numerical Python) کتابخانه‌ای برای محاسبات عددی هست که:

  • آرایه‌های چندبعدی (ndarray)
  • توابع ریاضی پیشرفته
  • عملیات بردار و ماتریس
  • سرعت بالا (C++ در پس‌زمینه)

💡 نصب: pip install numpy

💻 ساخت آرایه

import numpy as np

# آرایه از لیست
a = np.array([1, 2, 3, 4, 5])
print("آرایه ۱D:", a)

# آرایه ۲D
b = np.array([[1, 2, 3], [4, 5, 6]])
print("آرایه ۲D:\n", b)

# آرایه از range
c = np.arange(0, 10, 2)
print("arange:", c)

# آرایه از اعداد یکنواخت
d = np.linspace(0, 1, 5)
print("linspace:", d)

# آرایه صفر
e = np.zeros((3, 4))
print("zeros:\n", e)

# آرایه یک
f = np.ones((2, 3))
print("ones:\n", f)

# ماتریس هویت
g = np.eye(4)
print("eye:\n", g)

💻 عملیات ماتریسی

import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

# ضرب ماتریسی
print("ضرب ماتریسی:\n", np.dot(A, B))
print("ضرب ماتریسی (با @):\n", A @ B)

# ترانهاده
print("ترانهاده A:\n", A.T)

# دترمینان
print("دترمینان A:", np.linalg.det(A))

# معکوس
print("معکوس A:\n", np.linalg.inv(A))

# مقادیر ویژه
eigenvalues, eigenvectors = np.linalg.eig(A)
print("مقادیر ویژه:", eigenvalues)

arr = np.array([10, 20, 30, 40, 50])

np.random.shuffle(arr)

💻 ذخیره و خواندن

import numpy as np

a = np.array([1, 2, 3, 4, 5])

# ذخیره در فایل
np.save("array.npy", a)

# خواندن از فایل
b = np.load("array.npy")
print("بارگیری:", b)

# ذخیره به صورت txt
np.savetxt("array.txt", a, fmt="%d")

# خواندن از txt
c = np.loadtxt("array.txt")
print("بارگیری از txt:", c)

# ذخیره چند آرایه
np.savez("arrays.npz", arr1=a, arr2=b*2)
data = np.load("arrays.npz")
print("arr1:", data["arr1"])
print("arr2:", data["arr2"])

💡 نکته‌ی هوشمندانه

از NumPy برای بهینه‌سازی سرعت استفاده کن:

import numpy as np
import time

# روش پایتون (کند)
start = time.time()
result = [i ** 2 for i in range(1000000)]
print(f"پایتون: {time.time() - start:.3f}s")

# روش NumPy (سریع)
start = time.time()
result = np.arange(1000000) ** 2
print(f"NumPy: {time.time() - start:.3f}s")

تفاوت سرعت می‌تونه ۵۰ تا ۱۰۰ برابر باشه!

✍️ تمرین‌ها

تمرین ۱: آرایه‌ای از اعداد ۰ تا ۱۰۰ بساز و میانگین، میانه و انحراف معیار رو حساب کن.

تمرین ۲: یک ماتریس ۵×۵ از اعداد تصادفی بساز و ترانهاده و دترمینانش رو حساب کن.

تمرین ۳: دو آرایه ۱×۱۰ بساز و ضرب داخلی (dot product)شون رو حساب کن.
