📦 درس ۳۹: محیط مجازی و pip

سطح: پیشرفته | زمان مطالعه: ۲۰ دقیقه

🎯 هدف این درس

توی این درس با محیط مجازی (Virtual Environment) و pip آشنا میشی که برای مدیریت پکیج‌ها و پروژه‌ها خیلی مهم هستن.

📖 محیط مجازی چیست؟

محیط مجازی (venv) یه فضای جداگانه برای هر پروژه هست که پکیج‌ها رو از هم جدا نگه می‌داره.

  • جلوگیری از تداخل پکیج‌ها
  • هر پروژه پکیج‌های خودش رو داره
  • امکان استفاده از نسخه‌های مختلف

💡 یادت باشه: همیشه از محیط مجازی برای پروژه‌هات استفاده کن!

💻 ایجاد محیط مجازی

در خط فرمان:

# ایجاد محیط مجازی
python -m venv myenv

# فعال‌سازی در ویندوز
myenv\Scripts\activate

# فعال‌سازی در لینوکس/Mac
source myenv/bin/activate

# غیرفعال‌سازی
deactivate

💻 کار با pip

مدیریت پکیج‌ها:

# نصب پکیج
pip install requests
pip install numpy
pip install pandas

# نصب نسخه خاص
pip install requests==2.28.0

# نصب چند پکیج
pip install requests numpy pandas

# مشاهده پکیج‌های نصب شده
pip list
pip freeze

# حذف پکیج
pip uninstall requests

# به‌روزرسانی پکیج
pip install --upgrade requests

# ذخیره پکیج‌ها در فایل
pip freeze > requirements.txt

# نصب از فایل
pip install -r requirements.txt

💻 ساخت requirements.txt

# ایجاد requirements.txt
# در خط فرمان:
# pip freeze > requirements.txt

# محتوای فایل:
# requests==2.28.0
# numpy==1.24.0
# pandas==1.5.0

💻 مدیریت نسخه‌های پایتون

# بررسی نسخه پایتون
python --version

# ایجاد محیط با نسخه خاص
# روی ویندوز:
py -3.9 -m venv myenv

# روی لینوکس:
python3.9 -m venv myenv

💻 نصب از روی requirements.txt

# ایجاد محیط مجازی
python -m venv myenv

# فعال‌سازی
# ویندوز: myenv\Scripts\activate
# لینوکس: source myenv/bin/activate

# نصب پکیج‌ها
pip install -r requirements.txt

# اجرای برنامه
python main.py

💻 ساخت پکیج خودمان

# ساختار پکیج:
mypackage/
├── mypackage/
│   ├── __init__.py
│   ├── module1.py
│   └── module2.py
├── setup.py
└── README.md

# فایل setup.py:
from setuptools import setup, find_packages

setup(
    name="mypackage",
    version="1.0.0",
    packages=find_packages(),
    install_requires=[
        "requests>=2.28.0",
    ],
    author="Your Name",
    description="My awesome package",
)

# نصب پکیج:
# pip install -e .

💻 pipenv جایگزین venv

# نصب pipenv
pip install pipenv

# ایجاد محیط
pipenv install

# نصب پکیج
pipenv install requests

# نصب برای توسعه
pipenv install --dev pytest

# اجرا در محیط
pipenv run python main.py

# فعال‌سازی shell
pipenv shell

💻 poetry جایگزین venv + pip

# نصب poetry
curl -sSL https://install.python-poetry.org | python3 -

# ایجاد پروژه
poetry new myproject

# نصب پکیج
poetry add requests

# نصب برای توسعه
poetry add --dev pytest

# اجرا
poetry run python main.py

# فعال‌سازی shell
poetry shell

💡 نکته‌ی هوشمندانه

از .gitignore برای نادیده گرفتن پوشه‌های محیط مجازی استفاده کن:

# .gitignore
venv/
env/
myenv/
*.pyc
__pycache__/
*.log

برای ایجاد سریع محیط با پکیج‌های مورد نیاز:

# requirements. txt رو ایجاد کن
# و بعد از clone پروژه:
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

✍️ تمرین‌ها

تمرین ۱ (ساده): یک محیط مجازی جدید بساز و یک پکیج توش نصب کن.

تمرین ۲ (متوسط): یک requirements.txt برای پروژه‌ای که ۳ پکیج داره بساز.

تمرین ۳ (چالش‌برانگیز): یک پکیج ساده با دو تابع بساز و در محیط مجازی نصب کن.
