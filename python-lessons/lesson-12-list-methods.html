🛠️ درس ۱۲: متدهای لیست

سطح: مبتدی | زمان مطالعه: ۱۸ دقیقه

🎯 هدف این درس

توی این درس با متدهای لیست آشنا میشی. متدها ابزارهایی هستن که کارهای مختلفی روی لیست انجام می‌دن مثل مرتب‌سازی، جستجو، شمارش و ...

📖 متدهای لیست چیست؟

لیست‌ها در پایتون یه سری متد دارن که کارهای مختلفی روشون انجام می‌دن. این متدها با نقطه (.) به لیست متصل میشن.

مثلاً لیست.append() یا لیست.sort().

💻 متد append()

یک عضو به انتهای لیست اضافه می‌کنه:

میوه‌ها = ["سیب", "موز"]
میوه‌ها.append("پرتقال")
میوه‌ها.append("انگور")
print(میوه‌ها)
خروجی: 
['سیب', 'موز', 'پرتقال', 'انگور']

💻 متد insert()

یک عضو رو در جای مشخص از لیست اضافه می‌کنه:

میوه‌ها = ["سیب", "موز", "پرتقال"]
میوه‌ها.insert(1, "انگور")  # در ایندکس ۱
print(میوه‌ها)
خروجی: 
['سیب', 'انگور', 'موز', 'پرتقال']

💻 متد extend()

چند عضو رو به انتهای لیست اضافه می‌کنه:

میوه‌ها = ["سیب", "موز"]
میوه‌ها.extend(["پرتقال", "انگور", "هلو"])
print(میوه‌ها)
خروجی: 
['سیب', 'موز', 'پرتقال', 'انگور', 'هلو']

💡 نکته: تفاوت append() و extend(): append() یک عضو اضافه می‌کنه، extend() چند عضو.

💻 متد pop()

یک عضو رو از لیست حذف می‌کنه و برمی‌گردونه:

میوه‌ها = ["سیب", "موز", "پرتقال", "انگور"]

# حذف آخرین عضو
آخرین = میوه‌ها.pop()
print(آخرین)
print(میوه‌ها)

# حذف عضو مشخص
حذف_شده = میوه‌ها.pop(1)  # ایندکس ۱
print(حذف_شده)
print(میوه‌ها)
خروجی: 
انگور
['سیب', 'موز', 'پرتقال']
موز
['سیب', 'پرتقال']

💻 متد remove()

اولین عضوی که با مقدار مشخص برابر باشه رو حذف می‌کنه:

میوه‌ها = ["سیب", "موز", "پرتقال", "موز"]
میوه‌ها.remove("موز")  # فقط اولین موز رو حذف می‌کنه
print(میوه‌ها)
خروجی: 
['سیب', 'پرتقال', 'موز']

💻 متد index()

ایندکس اولین عضوی که با مقدار مشخص برابر باشه رو برمی‌گردونه:

میوه‌ها = ["سیب", "موز", "پرتقال", "انگور"]
ایندکس = میوه‌ها.index("پرتقال")
print(ایندکس)
خروجی: 
2

⚠️ هشدار: اگر مقدار مورد نظر در لیست نباشه، ارور میده.

💻 متد count()

تعداد دفعاتی که یک مقدار خاص توی لیست هست رو برمی‌گردونه:

اعداد = [1, 2, 3, 2, 4, 2, 5]
تعداد = اعداد.count(2)
print("عدد ۲ چند بار تکرار شده؟", تعداد)
خروجی: 
عدد ۲ چند بار تکرار شده؟ 3

💻 متد sort()

لیست رو مرتب می‌کنه (به‌صورت صعودی):

اعداد = [5, 2, 8, 1, 9, 3]
اعداد.sort()
print(اعداد)

# مرتب‌سازی نزولی
اعداد.sort(reverse=True)
print(اعداد)

# مرتب‌سازی متن‌ها (الفبایی)
میوه‌ها = ["هندوانه", "سیب", "موز", "انگور"]
میوه‌ها.sort()
print(میوه‌ها)
خروجی: 
[1, 2, 3, 5, 8, 9]
[9, 8, 5, 3, 2, 1]
['انگور', 'سیب', 'موز', 'هندوانه']

💻 متد reverse()

لیست رو برعکس می‌کنه:

اعداد = [1, 2, 3, 4, 5]
اعداد.reverse()
print(اعداد)
خروجی: 
[5, 4, 3, 2, 1]

💻 متد copy()

یک کپی از لیست می‌سازه:

a = [1, 2, 3]
b = a.copy()  # کپی واقعی
b[0] = 100
print("a:", a)
print("b:", b)
خروجی: 
a: [1, 2, 3]
b: [100, 2, 3]

💻 متد clear()

همه‌ی اعضای لیست رو پاک می‌کنه:

میوه‌ها = ["سیب", "موز", "پرتقال"]
میوه‌ها.clear()
print(میوه‌ها)
خروجی: 
[]

💻 متدهای max() و min() و sum()

این‌ها توابع داخلی پایتون هستن، نه متدهای لیست:

اعداد = [10, 5, 8, 20, 3]

print("بزرگترین:", max(اعداد))
print("کوچکترین:", min(اعداد))
print("مجموع:", sum(اعداد))
print("تعداد اعضا:", len(اعداد))
print("میانگین:", sum(اعداد) / len(اعداد))
خروجی: 
بزرگترین: 20
کوچکترین: 3
مجموع: 46
تعداد اعضا: 5
میانگین: 9.2

🧠 اشتباهات رایج

❌ اشتباه: فراموش کردن پرانتز بعد از متدها: لیست.sort

✅ راه‌حل: همیشه پرانتز بذار: لیست.sort()

❌ اشتباه: استفاده از remove() برای عضوی که وجود نداره:

میوه‌ها = ["سیب", "موز"]
میوه‌ها.remove("پرتقال")  # ارور!

✅ راه‌حل: اول با in چک کن که وجود داره یا نه.

❌ اشتباه: تغییر لیست حین حلقه for:

for میوه in میوه‌ها:
    if میوه == "موز":
        میوه‌ها.remove(میوه)  # خطرناک!

✅ راه‌حل: از کپی لیست استفاده کن: for میوه in میوه‌ها.copy():

💡 نکته‌ی هوشمندانه

برای مرتب‌سازی بدون تغییر لیست اصلی، از sorted() استفاده کن:

a = [5, 2, 8, 1]
b = sorted(a)  # لیست جدید مرتب
print("a:", a)  # [5, 2, 8, 1] (تغییر نکرده)
print("b:", b)  # [1, 2, 5, 8]

برای برعکس کردن بدون تغییر: list(reversed(a))

✍️ تمرین‌ها

تمرین ۱ (ساده): لیستی از اعداد بساز و با sort() مرتبش کن.

تمرین ۲ (متوسط): لیستی از اعداد بساز و با reverse() برعکسش کن.

تمرین ۳ (چالش‌برانگیز): برنامه‌ای بنویس که از کاربر ۱۰ عدد بگیره، توی لیست ذخیره کنه و سپس:
۱. لیست رو مرتب کنه
۲. بزرگترین و کوچکترین رو پیدا کنه
۳. تعداد اعداد زوج رو بشماره
