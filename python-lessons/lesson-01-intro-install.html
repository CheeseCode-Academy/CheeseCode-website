🐍 درس ۱: پایتون چیه؟ نصب و راه‌اندازی

سطح: مبتدی | زمان مطالعه: ۱۵ دقیقه

🎯 هدف این درس

توی این درس یاد می‌گیری که پایتون چیه، چرا باید یادش بگیری، و چطور توی کامپیوتر خودت نصبش کنی تا بتونی کد بزنی.

📖 پایتون چیست؟

پایتون یه زبان برنامه‌نویسی هست. یعنی زبانی که به کمک اون می‌تونی به کامپیوتر بگی چیکار کنه.

فرض کن پایتون مثل یه زبان واسطه بین تو و کامپیوتره. تو به زبان خودت (پایتون) به کامپیوتر می‌گی "این کار رو برام انجام بده" و کامپیوتر اون رو انجام میده.

💡 یادت باشه: کامپیوترها فقط زبان ۰ و ۱ (باینری) رو می‌فهمن. پایتون این کدها رو برای کامپیوتر ترجمه می‌کنه!

🤔 چرا پایتون؟

  • ساده و خواناست: کدهای پایتون مثل انگلیسی ساده‌ست.
  • قدرتمنده: از هوش مصنوعی تا ساخت وب‌سایت، همه‌جا کاربرد داره.
  • محبوبیت بالا: یکی از پرکاربردترین زبان‌های دنیاست.
  • رایگانه: هیچ هزینه‌ای نداره.

💻 نصب پایتون روی ویندوز

نصب پایتون خیلی سادست. قدم‌های زیر رو دقیق انجام بده:

قدم ۱: دانلود پایتون

به سایت رسمی پایتون برو: python.org یا اگه بخوای از سایت دانلود کنی برو صفحه‌ی دانلود ها

روی دکمه‌ی زرد رنگ Download Python کلیک کن. (خودش آخرین نسخه رو بهت پیشنهاد میده)

قدم ۲: اجرای فایل نصب

فایل دانلود شده رو اجرا کن. (اسمش چیزی مثل python-3.14.0.exe هست)

⚠️ خیلی مهم: توی صفحه‌ی اول نصب، حتماً تیک گزینه‌ی "Add Python to PATH" رو بزن! این کار باعث میشه بتونی از هر جایی پایتون رو اجرا کنی.

قدم ۳: نصب

روی Install Now کلیک کن و صبر کن تا نصب تموم بشه.

وقتی پیام "Setup was successful" رو دیدی، یعنی نصب کامل شده!

قدم ۴: تست نصب

برای اینکه مطمئن بشی پایتون درست نصب شده:

  • کلیدهای Win + R رو بزن.
  • توی پنجره‌ی باز شده cmd رو بنویس و Enter بزن تا خط فرمان (Command Prompt) باز بشه.
  • توی خط فرمان python --version رو تایپ کن و Enter بزن.

اگر نوشته Python 3.14.0 یا چیزی شبیه این رو دیدی، یعنی نصب موفقیت‌آمیز بوده! 🎉

📝 اولین کد پایتون

حالا که پایتون رو نصب کردی، بیا اولین کد رو بنویسیم.

توی خط فرمان (همون CMD که باز کردی)، این رو تایپ کن:

python

با این کار وارد محیط تعاملی پایتون میشی. یعنی می‌تونی دستورات پایتون رو مستقیم تایپ کنی و نتیجه رو ببینی.

حالا این کد رو تایپ کن:

print("سلام دنیا!")
خروجی: 
سلام دنیا!

تبریک! 🎉 تو اولین کد پایتون رو نوشتی! print یعنی "چاپ کن" و به پایتون می‌گه که متن داخل پرانتز رو نمایش بده.

💡 نکته: برای خروج از محیط تعاملی پایتون، دستور exit() رو تایپ کن و Enter بزن.

🧠 اشتباهات رایج

❌ اشتباه: فراموش کردن تیک "Add Python to PATH" موقع نصب.

✅ راه‌حل: اگر این کار رو نکردی، پایتون رو دوباره نصب کن و این بار تیکش رو بزن.

❌ اشتباه: تایپ کردن print(سلام دنیا) بدون کوتیشن (" ").

✅ راه‌حل: همیشه متن رو داخل " " یا ' ' قرار بده.

💡 نکته‌ی هوشمندانه

به‌جای خط فرمان (CMD)، می‌تونی از IDLE استفاده کنی که با پایتون نصب میشه. IDLE یه محیط ساده‌تر و کاربردی‌تر برای نوشتن کد پایتونه. توی منوی استارت، IDLE رو جستجو کن و بازش کن.

✍️ تمرین‌ها

تمرین ۱ (ساده): پایتون رو روی کامپیوترت نصب کن و با دستور python --version نسخه‌اش رو چک کن.

تمرین ۲ (متوسط): توی محیط تعاملی پایتون، سه چیز مختلف رو با print چاپ کن. مثلاً اسم خودت، اسم شهرت و غذای مورد علاقت.

تمرین ۳ (چالش‌برانگیز): توی خط فرمان (CMD)، بدون اینکه وارد محیط پایتون بشی، می‌تونی با دستور python -c "print('سلام')" مستقیم کد رو اجرا کنی. امتحان کن!
