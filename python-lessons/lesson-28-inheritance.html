👨‍👩‍👦 درس ۲۸: وراثت (Inheritance)

سطح: متوسط | زمان مطالعه: ۲۰ دقیقه

🎯 هدف این درس

توی این درس با وراثت آشنا میشی که به کلاس‌ها اجازه میده ویژگی‌ها و متدهای کلاس دیگه‌ای رو به ارث ببرن.

📖 وراثت چیست؟

وراثت (Inheritance) به کلاس‌ها اجازه میده که از کلاس دیگه‌ای ارث‌بری کنن. کلاسی که ارث می‌بره، کلاس فرزند (Child) و کلاسی که ازش ارث برده میشه، کلاس والد (Parent) نامیده میشه.

فرض کن کلاس ماشین (والد) و کلاس پژو (فرزند) داریم. پژو همه‌ی ویژگی‌های ماشین رو داره + ویژگی‌های خودش.

💡 یادت باشه: وراثت باعث کاهش کد تکراری و افزایش قابلیت استفاده میشه.

💻 وراثت ساده

class حیوان:
    def __init__(self, نام):
        self.نام = نام
    
    def صدا_بده(self):
        return "حیوان صدا می‌دهد"

class سگ(حیوان):
    def صدا_بده(self):
        return "هاپ هاپ!"

class گربه(حیوان):
    def صدا_بده(self):
        return "میو میو!"

سگ_من = سگ("رکس")
گربه_من = گربه("پیشی")

print(سگ_من.نام)  # رکس
print(سگ_من.صدا_بده())  # هاپ هاپ!
print(گربه_من.صدا_بده())  # میو میو!

💻 استفاده از super()

super() به متدهای کلاس والد دسترسی میده:

class شخص:
    def __init__(self, نام, سن):
        self.نام = نام
        self.سن = سن
    
    def معرفی(self):
        return f"من {self.نام} هستم"

class دانشجو(شخص):
    def __init__(self, نام, سن, رشته):
        super().__init__(نام, سن)  # فراخوانی سازنده والد
        self.رشته = رشته
    
    def معرفی(self):
        return f"{super().معرفی()} و رشته‌ام {self.رشته} است"

علی = دانشجو("علی", 25, "مهندسی کامپیوتر")
print(علی.معرفی())
خروجی: 
من علی هستم و رشته‌ام مهندسی کامپیوتر است

💻 چندریختی (Polymorphism)

class حیوان:
    def صدا_بده(self):
        pass

class سگ(حیوان):
    def صدا_بده(self):
        return "هاپ هاپ!"

class گربه(حیوان):
    def صدا_بده(self):
        return "میو میو!"

class گاو(حیوان):
    def صدا_بده(self):
        return "مــــووو!"

def گوش_کن(حیوان):
    print(حیوان.صدا_بده())

گوش_کن(سگ())
گوش_کن(گربه())
گوش_کن(گاو())
خروجی: 
هاپ هاپ!
میو میو!
مــــووو!

💻 وراثت چندگانه

پایتون از وراثت چندگانه پشتیبانی می‌کنه:

class پرنده:
    def پرواز_کن(self):
        return "پرنده در حال پرواز"

class ماهی:
    def شنا_کن(self):
        return "ماهی در حال شنا"

class مرغ_ابی(پرنده, ماهی):
    def رفتار(self):
        return f"{self.proاز_کن()} و {self.شنا_کن()}"

مرغ = مرغ_ابی()
print(مرغ.رفتار())
خروجی: 
پرنده در حال پرواز و ماهی در حال شنا

💻 MRO (Method Resolution Order)

ترتیب جستجوی متدها:

class A:
    def متد(self):
        return "A"

class B(A):
    def متد(self):
        return "B"

class C(A):
    def متد(self):
        return "C"

class D(B, C):
    pass

d = D()
print(d.متد())  # B
print(D.__mro__)  # ترتیب جستجو
خروجی: 
B
(<class '__main__.D'>, <class '__main__.B'>, <class '__main__.C'>, <class '__main__.A'>, <class 'object'>)

💻 isinstance() و issubclass()

class حیوان: pass
class سگ(حیوان): pass

سگ_من = سگ()

print(isinstance(سگ_من, سگ))  # True
print(isinstance(سگ_من, حیوان))  # True
print(issubclass(سگ, حیوان))  # True
print(issubclass(حیوان, سگ))  # False

🧠 اشتباهات رایج

❌ اشتباه: فراموش کردن super().__init__() در کلاس فرزند

✅ راه‌حل: همیشه سازنده والد رو صدا بزن تا ویژگی‌ها مقداردهی بشن.

❌ اشتباه: وراثت چندگانه با کلاس‌های هم‌نام

✅ راه‌حل: از __mro__ برای فهمیدن ترتیب استفاده کن.

💡 نکته‌ی هوشمندانه

از وراثت ترکیبی (Mixins) برای اضافه کردن قابلیت‌ها استفاده کن:

class JSONMixin:
    def to_json(self):
        import json
        return json.dumps(self.__dict__)

class شخص(JSONMixin):
    def __init__(self, نام, سن):
        self.نام = نام
        self.سن = سن

علی = شخص("علی", 25)
print(علی.to_json())  # {"نام": "علی", "سن": 25}

✍️ تمرین‌ها

تمرین ۱ (ساده): کلاس شکل بساز و کلاس‌های مستطیل و دایره ازش ارث ببرن.

تمرین ۲ (متوسط): کلاس کارمند و مدیر بساز که مدیر از کارمند ارث ببره و حقوق بیشتری داشته باشه.

تمرین ۳ (چالش‌برانگیز): با وراثت چندگانه، کلاس پرنده_شناگر بساز که هم پرواز کنه هم شنا.
