📥 درس ۱۷: پارامترها و مقدار برگشتی

سطح: مبتدی | زمان مطالعه: ۱۸ دقیقه

🎯 هدف این درس

توی این درس با پارامترها و مقدار برگشتی بیشتر آشنا میشی و یاد می‌گیری چطور توابع قدرتمندتری بنویسی.

📖 انواع پارامترها

  • پارامترهای اجباری - حتماً باید مقدار بدی
  • پارامترهای اختیاری - می‌تونی مقدار پیش‌فرض بدی
  • پارامترهای کلیدواژه‌ای - با اسم پارامتر مقدار می‌دی

💻 پارامترهای اجباری

def جمع(a, b):  # a و b اجباری هستن
    return a + b

print(جمع(5, 3))   # درسته
# print(جمع(5))    # ارور! یک پارامتر کمه
خروجی: 
8

💻 پارامترهای اختیاری (پیش‌فرض)

def سلام(نام, رسمی=False):
    if رسمی:
        print(f"جناب {نام}، خوش آمدید!")
    else:
        print(f"سلام {نام}!")

سلام("علی")           # رسمی=False (پیش‌فرض)
سلام("زهرا", True)   # رسمی=True
خروجی: 
سلام علی!
جناب زهرا، خوش آمدید!

💻 پارامترهای کلیدواژه‌ای

با اسم پارامتر مقدار می‌دی، ترتیب مهم نیست:

def معرفی(نام, سن, شهر):
    print(f"{نام}، {سن} ساله، اهل {شهر}")

# روش عادی (با ترتیب)
معرفی("علی", 25, "تهران")

# روش کلیدواژه‌ای (ترتیب مهم نیست)
معرفی(شهر="اصفهان", نام="زهرا", سن=30)
خروجی: 
علی، 25 ساله، اهل تهران
زهرا، 30 ساله، اهل اصفهان

💻 *args (پارامترهای متغیر)

*args به تابع اجازه میده هر تعداد پارامتر دریافت کنه:

def جمع_همه(*اعداد):
    مجموع = 0
    for عدد in اعداد:
        مجموع += عدد
    return مجموع

print(جمع_همه(1, 2, 3))
print(جمع_همه(10, 20, 30, 40, 50))
print(جمع_همه(5, 5, 5, 5))
خروجی: 
6
150
20

💡 نکته: *args یه تاپل از پارامترها رو می‌گیره.

💻 **kwargs (پارامترهای کلیدواژه‌ای متغیر)

**kwargs به تابع اجازه میده هر تعداد پارامتر کلیدواژه‌ای دریافت کنه:

def نمایش_اطلاعات(**اطلاعات):
    for کلید, مقدار in اطلاعات.items():
        print(f"{کلید}: {مقدار}")
    print("---")

نمایش_اطلاعات(نام="علی", سن=25, شهر="تهران")
نمایش_اطلاعات(نام="زهرا", سن=30, شهر="اصفهان", رشته="مهندسی")
خروجی: 
نام: علی
سن: 25
شهر: تهران
---
نام: زهرا
سن: 30
شهر: اصفهان
رشته: مهندسی
---

💻 ترکیب *args و **kwargs

def تابع_کامل(نام, *علاقه‌مندی‌ها, **اطلاعات):
    print(f"نام: {نام}")
    print("علاقه‌مندی‌ها:", علاقه‌مندی‌ها)
    print("اطلاعات دیگر:", اطلاعات)

تابع_کامل("علی", "برنامه‌نویسی", "ورزش", "موسیقی", سن=25, شهر="تهران")
خروجی: 
نام: علی
علاقه‌مندی‌ها: ('برنامه‌نویسی', 'ورزش', 'موسیقی')
اطلاعات دیگر: {'سن': 25, 'شهر': 'تهران'}

💻 مقدار برگشتی پیشرفته

می‌تونی هر چیزی رو برگردونی: عدد، متن، لیست، دیکشنری، حتی تابع!

def تجزیه_و_تحلیل(لیست):
    return {
        "تعداد": len(لیست),
        "مجموع": sum(لیست),
        "بزرگترین": max(لیست),
        "کوچکترین": min(لیست),
        "میانگین": sum(لیست) / len(لیست)
    }

اعداد = [10, 20, 30, 40, 50]
نتیجه = تجزیه_و_تحلیل(اعداد)

for کلید, مقدار in نتیجه.items():
    print(f"{کلید}: {مقدار}")
خروجی: 
تعداد: 5
مجموع: 150
بزرگترین: 50
کوچکترین: 10
میانگین: 30.0

💻 تابع بدون return

اگر return نباشه، تابع None برمی‌گردونه:

def بدون_بازگشت():
    print("این تابع چیزی برنمی‌گردونه")

نتیجه = بدون_بازگشت()
print("مقدار برگشتی:", نتیجه)
خروجی: 
این تابع چیزی برنمی‌گردونه
مقدار برگشتی: None

🧠 اشتباهات رایج

❌ اشتباه: استفاده از متغیر تغییرپذیر به عنوان مقدار پیش‌فرض:

def تابع(لیست=[]):  # خطرناک!
    لیست.append(1)
    return لیست

✅ راه‌حل: از None به عنوان پیش‌فرض استفاده کن:

def تابع(لیست=None):
    if لیست is None:
        لیست = []
    لیست.append(1)
    return لیست

❌ اشتباه: فراموش کردن return وقتی که باید مقداری برگردونه:

def جمع(a, b):
    a + b  # return رو فراموش کردی!

✅ راه‌حل: حتماً از return استفاده کن: return a + b

💡 نکته‌ی هوشمندانه

می‌تونی از * برای باز کردن لیست یا تاپل موقع صدا زدن تابع استفاده کنی:

def جمع_سه(a, b, c):
    return a + b + c

اعداد = [10, 20, 30]
print(جمع_سه(*اعداد))  # 60

به این می‌گن Unpacking.

✍️ تمرین‌ها

تمرین ۱ (ساده): تابعی بنویس که دو عدد بگیره و حاصل ضربشون رو برگردونه.

تمرین ۲ (متوسط): تابعی بنویس که یک لیست از اعداد بگیره و مجموع و میانگین رو به صورت دیکشنری برگردونه.

تمرین ۳ (چالش‌برانگیز): تابعی بنویس که با *args هر تعداد عدد بگیره و بزرگترینشون رو پیدا کنه.
