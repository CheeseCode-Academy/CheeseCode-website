⚙️ درس ۱۶: توابع (Functions)

سطح: مبتدی | زمان مطالعه: ۱۸ دقیقه

🎯 هدف این درس

توی این درس با توابع آشنا میشی. توابع بهت کمک می‌کنن کدهای تکراری رو سازماندهی کنی و ازشون دوباره استفاده کنی.

📖 تابع چیست؟

تابع (Function) یه بلوک کد هست که یه کار خاص رو انجام میده. با تعریف کردن یه تابع، می‌تونی هر وقت که خواستی اون رو صدا بزنی و ازش استفاده کنی.

فرض کن تابع مثل یه دستور پخت هست. یه بار دستور رو می‌نویسی، ولی هر وقت که خواستی می‌تونی ازش استفاده کنی و غذا درست کنی.

💡 یادت باشه: توابع با کلمه‌ی کلیدی def تعریف میشن و بعد از اسم تابع، پرانتز ( ) و دونقطه (:) می‌ذاریم.

💻 تعریف تابع ساده

def سلام():
    print("سلام به همه!")
    print("خوش آمدید!")

# صدا زدن تابع
سلام()
سلام()
خروجی: 
سلام به همه!
خوش آمدید!
سلام به همه!
خوش آمدید!

💡 نکته: تابع رو با اسمش و پرانتز صدا می‌زنیم: سلام()

💻 تابع با پارامتر

پارامترها ورودی‌های تابع هستن:

def سلام_به(نام):
    print("سلام", نام, "خوش آمدی!")

سلام_به("علی")
سلام_به("زهرا")
خروجی: 
سلام علی خوش آمدی!
سلام زهرا خوش آمدی!

💻 تابع با چند پارامتر

def معرفی(نام, سن, شهر):
    print(f"سلام! من {نام} هستم، {سن} ساله و اهل {شهر} هستم.")

معرفی("علی", 25, "تهران")
معرفی("زهرا", 30, "اصفهان")
خروجی: 
سلام! من علی هستم، 25 ساله و اهل تهران هستم.
سلام! من زهرا هستم، 30 ساله و اهل اصفهان هستم.

💻 تابع با مقدار برگشتی (return)

return یه مقدار رو از تابع برمی‌گردونه:

def جمع(a, b):
    return a + b

نتیجه = جمع(5, 3)
print("نتیجه جمع:", نتیجه)

# می‌تونی مستقیم توی print استفاده کنی
print("جمع ۱۰ و ۲۰:", جمع(10, 20))
خروجی: 
نتیجه جمع: 8
جمع ۱۰ و ۲۰: 30

💻 تابع با چند return

def بزرگترین(a, b):
    if a > b:
        return a
    else:
        return b

print(بزرگترین(10, 20))
print(بزرگترین(100, 50))
خروجی: 
20
100

💻 تابع بدون return

اگر تابع return نداشته باشه، None برمی‌گردونه:

def چاپ_کن(پیام):
    print(پیام)

نتیجه = چاپ_کن("سلام")
print("مقدار برگشتی:", نتیجه)
خروجی: 
سلام
مقدار برگشتی: None

💻 برگرداندن چند مقدار

با return می‌تونی چند مقدار رو به صورت تاپل برگردونی:

def آمار(لیست):
    return min(لیست), max(لیست), sum(لیست) / len(لیست)

اعداد = [10, 20, 30, 40, 50]
کوچک, بزرگ, میانگین = آمار(اعداد)
print(f"کوچک: {کوچک}, بزرگ: {بزرگ}, میانگین: {میانگین}")
خروجی: 
کوچک: 10, بزرگ: 50, میانگین: 30.0

💻 تابع با پارامتر پیش‌فرض

def سلام(نام, رسمی=False):
    if رسمی:
        print(f"جناب {نام}، خوش آمدید!")
    else:
        print(f"سلام {نام}!")

سلام("علی")
سلام("زهرا", True)
خروجی: 
سلام علی!
جناب زهرا، خوش آمدید!

💻 داک‌استرینگ (مستندات تابع)

با داک‌استرینگ می‌تونی تابع رو مستند کنی:

def جمع(a, b):
    """این تابع دو عدد رو جمع می‌کنه و نتیجه رو برمی‌گردونه."""
    return a + b

# دیدن مستندات
print(جمع.__doc__)
help(جمع)
خروجی: 
این تابع دو عدد رو جمع می‌کنه و نتیجه رو برمی‌گردونه.
(اطلاعات help)

🧠 اشتباهات رایج

❌ اشتباه: فراموش کردن : بعد از تعریف تابع: def سلام()

✅ راه‌حل: همیشه بعد از تعریف تابع دونقطه بذار: def سلام():

❌ اشتباه: استفاده از متغیرهای تابع بیرون از تابع:

def تابع():
    x = 10
print(x)  # ارور! x فقط داخل تابع هست

✅ راه‌حل: متغیر رو با return برگردون یا بیرون تعریفش کن.

❌ اشتباه: فراموش کردن پرانتز موقع صدا زدن تابع: سلام

✅ راه‌حل: همیشه با پرانتز صدا بزن: سلام()

💡 نکته‌ی هوشمندانه

می‌تونی توابع رو به عنوان پارامتر به توابع دیگه بدی:

def عملیات(a, b, تابع):
    return تابع(a, b)

def جمع(x, y):
    return x + y

def ضرب(x, y):
    return x * y

print(عملیات(5, 3, جمع))  # 8
print(عملیات(5, 3, ضرب))  # 15

به این می‌گن توابع درجه‌بالا.

✍️ تمرین‌ها

تمرین ۱ (ساده): تابعی بنویس که اسم کاربر رو بگیره و بهش سلام کنه.

تمرین ۲ (متوسط): تابعی بنویس که سه عدد بگیره و بزرگترینشون رو برگردونه.

تمرین ۳ (چالش‌برانگیز): تابعی بنویس که یه لیست از اعداد بگیره و مجموع اعداد زوج رو برگردونه.
