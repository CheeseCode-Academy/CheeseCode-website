🤔 درس ۷: شرط if

سطح: مبتدی | زمان مطالعه: ۱۴ دقیقه

🎯 هدف این درس

توی این درس یاد می‌گیری که چطور به برنامه‌ات قدرت تصمیم‌گیری بدی. یعنی برنامه بر اساس شرایط مختلف، کارهای مختلفی انجام بده.

📖 شرط if چیست؟

if به برنامه می‌گه که "اگر این شرط درست بود، این کار رو بکن".

فرض کن می‌خوای به یه ربات بگی: "اگر بارون می‌باره، چتر بردار". این دقیقاً همون کاریه که if انجام میده.

💡 یادت باشه: بعد از if همیشه دونقطه (:) می‌ذاریم و کدهایی که باید اجرا بشن رو با فاصله (indentation) تو خط بعد می‌نویسیم.

💻 ساختار if

سن = int(input("سن خود را وارد کنید: "))

if سن >= 18:
    print("شما بزرگسال هستید")
    print("می‌توانید رانندگی کنید")
خروجی (نمونه ۱): 
سن خود را وارد کنید: 20
شما بزرگسال هستید
می‌توانید رانندگی کنید
خروجی (نمونه ۲): 
سن خود را وارد کنید: 15
(هیچ خروجی)

💡 نکته: اگه شرط درست نباشه، کدهای داخل if اجرا نمیشن و برنامه ادامه پیدا می‌کنه.

💻 if با else

else به برنامه می‌گه "اگر شرط درست نبود، این کار رو بکن":

سن = int(input("سن خود را وارد کنید: "))

if سن >= 18:
    print("شما بزرگسال هستید")
else:
    print("شما کودک یا نوجوان هستید")
خروجی (نمونه ۱): 
سن خود را وارد کنید: 20
شما بزرگسال هستید
خروجی (نمونه ۲): 
سن خود را وارد کنید: 15
شما کودک یا نوجوان هستید

💻 if با elif (چند شرط)

elif یعنی "اگر شرط اول درست نبود، این شرط رو چک کن". می‌تونی چندتا elif داشته باشی:

نمره = float(input("نمره خود را وارد کنید: "))

if نمره >= 18:
    print("عالی")
elif نمره >= 15:
    print("خوب")
elif نمره >= 12:
    print("متوسط")
else:
    print("نیاز به تلاش بیشتر")
خروجی (نمونه): 
نمره خود را وارد کنید: 16.5
خوب

💡 نکته: شرط‌ها از بالا به پایین بررسی میشن. به محض اینکه یه شرط درست بشه، بقیه نادیده گرفته میشن.

💻 if های تو در تو

می‌تونی داخل یه if یه if دیگه بذاری:

سن = int(input("سن خود را وارد کنید: "))
گواهینامه = input("آیا گواهینامه دارید؟ (بله/خیر): ")

if سن >= 18:
    if گواهینامه == "بله":
        print("می‌توانید رانندگی کنید")
    else:
        print("ابتدا گواهینامه بگیرید")
else:
    print("سن شما برای رانندگی مناسب نیست")
خروجی (نمونه): 
سن خود را وارد کنید: 22
آیا گواهینامه دارید؟ (بله/خیر): بله
می‌توانید رانندگی کنید

🧠 اشتباهات رایج

❌ اشتباه: فراموش کردن دونقطه (:) بعد از if: if سن > 18

✅ راه‌حل: همیشه بعد از if دونقطه بذار: if سن > 18:

❌ اشتباه: فراموش کردن فاصله (indentation) برای کدهای داخل if:

if سن > 18:
print("بزرگسال")  # اشتباه!

✅ راه‌حل: کدهای داخل if رو با فاصله (یا Tab) جلوتر ببر:

if سن > 18:
    print("بزرگسال")  # درست

❌ اشتباه: استفاده از = به جای == برای مقایسه: if نمره = 20:

✅ راه‌حل: برای مقایسه از == استفاده کن: if نمره == 20:

💡 نکته‌ی هوشمندانه

می‌تونی چند شرط رو با and و or ترکیب کنی:

سن = 25
گواهینامه = True

if سن >= 18 and گواهینامه == True:
    print("می‌توانید رانندگی کنید")
else:
    print("نمی‌توانید رانندگی کنید")

✍️ تمرین‌ها

تمرین ۱ (ساده): برنامه‌ای بنویس که از کاربر یک عدد بگیره و بگه که مثبت، منفی یا صفر هست.

تمرین ۲ (متوسط): برنامه‌ای بنویس که از کاربر سنش رو بپرسه و بر اساس سن، یکی از این پیام‌ها رو چاپ کنه:
کمتر از ۱۲: "کودک"
۱۲ تا ۱۸: "نوجوان"
۱۸ تا ۶۰: "بزرگسال"
بیشتر از ۶۰: "سالمند"

تمرین ۳ (چالش‌برانگیز): برنامه‌ای بنویس که سه عدد از کاربر بگیره و بگه که آیا می‌تونن سه ضلع یه مثلث باشن یا نه. (راهنمایی: در یک مثلث، مجموع هر دو ضلع باید از ضلع سوم بزرگتر باشه)
