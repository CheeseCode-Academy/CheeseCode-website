⚠️ درس ۲۲: مدیریت خطا (Exceptions)

سطح: متوسط | زمان مطالعه: ۱۸ دقیقه

🎯 هدف این درس

توی این درس یاد می‌گیری چطور خطاهای برنامه رو مدیریت کنی و از کرش کردن برنامه جلوگیری کنی.

📖 خطاها در پایتون

خطاها (Exceptions) وقتی رخ می‌دن که یه اتفاق غیرمنتظره توی برنامه بیفته. مثلاً تقسیم بر صفر یا باز کردن فایلی که وجود نداره.

با try و except می‌تونی خطاها رو گرفته و مدیریت کنی.

💡 یادت باشه: مدیریت خطا به برنامه‌ات قابلیت اطمینان میده و از کرش کردن جلوگیری می‌کنه.

💻 ساختار try/except

try:
    عدد = int(input("یک عدد وارد کنید: "))
    نتیجه = 10 / عدد
    print("نتیجه:", نتیجه)
except:
    print("خطایی رخ داد!")

یک عدد وارد کنید: 5
نتیجه: 2.0
خروجی (نمونه ۲): 
یک عدد وارد کنید: 0
خطایی رخ داد!
خروجی (نمونه ۳): 
یک عدد وارد کنید: سلام

💻 گرفتن خطاهای خاص

try:
    عدد = int(input("یک عدد وارد کنید: "))
    نتیجه = 10 / عدد
    print("نتیجه:", نتیجه)
except ValueError:
    print("خطا: لطفاً یک عدد وارد کنید!")
except ZeroDivisionError:
    print("خطا: تقسیم بر صفر ممکن نیست!")
except Exception as e:
    print(f"خطای ناشناخته: {e}")

💡 نکته: همیشه خطاهای خاص رو قبل از خطای کلی (Exception) بنویس.

💻 try/except/else/finally

try:
    عدد = int(input("یک عدد وارد کنید: "))
    نتیجه = 10 / عدد
except ZeroDivisionError:
    print("تقسیم بر صفر!")
except ValueError:
    print("عدد معتبر وارد کنید!")
else:
    print(f"نتیجه: {نتیجه}")  # اگر خطایی نبود
finally:
    print("این پیام همیشه اجرا میشه")
خروجی (نمونه): 
یک عدد وارد کنید: 5
نتیجه: 2.0
این پیام همیشه اجرا میشه

💻 raise (پرتاب خطا)

می‌تونی خودت خطا ایجاد کنی:

def سن_را_بررسی_کن(سن):
    if سن < 0:
        raise ValueError("سن نمی‌تواند منفی باشد!")
    elif سن > 120:
        raise ValueError("سن نمی‌تواند بیشتر از ۱۲۰ باشد!")
    return "سن معتبر است"

try:
    print(سن_را_بررسی_کن(25))
    print(سن_را_بررسی_کن(-5))
except ValueError as e:
    print(f"خطا: {e}")
خروجی: 
سن معتبر است
خطا: سن نمی‌تواند منفی باشد!

💻 خطاهای رایج در پایتون

  • ValueError - مقدار نامعتبر
  • TypeError - نوع داده نامعتبر
  • ZeroDivisionError - تقسیم بر صفر
  • FileNotFoundError - فایل پیدا نشد
  • IndexError - ایندکس خارج از محدوده
  • KeyError - کلید در دیکشنری وجود نداره

💻 مثال کامل

def خواندن_فایل(نام_فایل):
    try:
        with open(نام_فایل, "r") as فایل:
            return فایل.read()
    except FileNotFoundError:
        print(f"فایل {نام_فایل} پیدا نشد!")
        return None
    except PermissionError:
        print(f"دسترسی به فایل {نام_فایل} وجود ندارد!")
        return None
    except Exception as e:
        print(f"خطای ناشناخته: {e}")
        return None

محتوا = خواندن_فایل("test.txt")
if محتوا:
    print(محتوا)

🧠 اشتباهات رایج

❌ اشتباه: گرفتن همه خطاها با except: بدون مشخص کردن نوع خطا

✅ راه‌حل: حداقل از except Exception as e: استفاده کن تا نوع خطا رو بدونی.

❌ اشتباه: خالی گذاشتن except (بدون هیچ کدی)

✅ راه‌حل: حداقل یه پیام به کاربر نشون بده یا خطا رو لاگ کن.

❌ اشتباه: گرفتن خطا در کل برنامه و نادیده گرفتنش

✅ راه‌حل: فقط خطاهایی رو بگیر که می‌دونی چطور مدیریتشون کنی.

💡 نکته‌ی هوشمندانه

از else برای کدهایی که فقط وقتی خطایی نیست اجرا میشن استفاده کن:

try:
    فایل = open("data.txt", "r")
except FileNotFoundError:
    print("فایل پیدا نشد، فایل جدید می‌سازیم")
    فایل = open("data.txt", "w")
else:
    print("فایل با موفقیت باز شد")
    محتوا = فایل.read()
finally:
    فایل.close()

✍️ تمرین‌ها

تمرین ۱ (ساده): برنامه‌ای بنویس که از کاربر یک عدد بگیره و تقسیم ۱۰۰ بر اون رو انجام بده. خطای تقسیم بر صفر رو مدیریت کن.

تمرین ۲ (متوسط): برنامه‌ای بنویس که از کاربر یه فایل بخونه و محتواش رو چاپ کنه. خطای FileNotFoundError رو مدیریت کن.

تمرین ۳ (چالش‌برانگیز): تابعی بنویس که سن رو بگیره و اگر منفی یا بزرگتر از ۱۲۰ بود، خطا پرتاب کنه.
