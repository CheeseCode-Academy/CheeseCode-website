📦 درس ۲۰: ماژول‌ها و import

سطح: مبتدی | زمان مطالعه: ۱۸ دقیقه

🎯 هدف این درس

توی این درس با ماژول‌ها و import آشنا میشی. ماژول‌ها بهت کمک می‌کنن کدها رو سازماندهی کنی و از کدهای آماده استفاده کنی.

📖 ماژول چیست؟

ماژول (Module) یه فایل پایتون هست که شامل توابع، کلاس‌ها و متغیرهای مختلفه. با import می‌تونی از ماژول‌ها استفاده کنی.

فرض کن ماژول مثل یه کتابخانه هست که پر از ابزارهای آماده‌ست.

💡 یادت باشه: هر فایل .py یه ماژول هست و می‌تونی ازش import کنی.

💻 import ماژول‌های استاندارد

import math
import random
import datetime

# استفاده از math
print("عدد پی:", math.pi)
print("جذر ۱۶:", math.sqrt(16))

# استفاده از random
print("عدد تصادفی:", random.randint(1, 10))
print("انتخاب تصادفی:", random.choice(["سیب", "موز", "پرتقال"]))

# استفاده از datetime
اکنون = datetime.datetime.now()
print("تاریخ و زمان:", اکنون)
خروجی (نمونه):

جذر ۱۶: 4.0
عدد تصادفی: 7
انتخاب تصادفی: موز
تاریخ و زمان: 2026-07-21 14:30:25.123456

💻 import با اسم مستعار (alias)

import math as m
import datetime as dt

print(m.pi)
print(dt.datetime.now())
خروجی (نمونه): 
3.141592653589793
2026-07-21 14:30:25.123456

💻 import فقط بخشی از ماژول

from math import pi, sqrt
from random import randint, choice

print("pi:", pi)
print("جذر ۲۵:", sqrt(25))
print("عدد تصادفی:", randint(1, 100))
print("انتخاب:", choice(["الف", "ب", "ج"]))

💡 نکته: این روش باعث میشه کد کوتاه‌تر بشه، ولی ممکنه نام‌ها با هم تداخل پیدا کنن.

💻 import همه چیز (توصیه نمی‌شه)

from math import *

print(pi)
print(sqrt(16))
print(cos(0))

💻 ساخت ماژول خودمان

فرض کن فایل ابزار.py رو می‌سازیم:

# فایل: ابزار.py
def سلام(نام):
    return f"سلام {نام}!"

def جمع(a, b):
    return a + b

پیش‌فرض = "سلام"

حالا می‌تونیم ازش استفاده کنیم:

import ابزار

print(ابزار.سلام("علی"))
print(ابزار.جمع(5, 3))
print(ابزار.پیش‌فرض)
خروجی: 
سلام علی!
8
سلام

💻 ماژول‌های مفید استاندارد

import os
import sys
import json
import time

# os - کار با سیستم عامل
print("پوشه فعلی:", os.getcwd())

# sys - اطلاعات سیستم
print("نسخه پایتون:", sys.version)

# json - کار با JSON
data = {"نام": "علی", "سن": 25}
json_string = json.dumps(data)
print("JSON:", json_string)

# time - زمان
time.sleep(1)  # ۱ ثانیه توقف
print("بعد از ۱ ثانیه")
خروجی (نمونه): 
پوشه فعلی: /home/user
نسخه پایتون: 3.14.0
JSON: {"نام": "علی", "سن": 25}
بعد از ۱ ثانیه

💻 __name__ و __main__

برای تشخیص اینکه فایل به عنوان ماژول import شده یا مستقیم اجرا شده:

# فایل: مثال.py
def تابع():
    print("این یک تابع است")

if __name__ == "__main__":
    print("این فایل مستقیم اجرا شده")
    تابع()
else:
    print("این فایل به عنوان ماژول import شده")

🧠 اشتباهات رایج

❌ اشتباه: نامگذاری فایل با اسم ماژول استاندارد: math.py

✅ راه‌حل: از اسم‌های منحصربه‌فرد استفاده کن: ریاضی_من.py

❌ اشتباه: فراموش کردن import ماژول:

print(math.pi)  # ارور! math import نشده

✅ راه‌حل: اول import math کن.

❌ اشتباه: استفاده از from module import *:

✅ راه‌حل: از این کار خودداری کن. به‌جاش دقیقاً مشخص کن چی می‌خوای:

from math import pi, sqrt

💡 نکته‌ی هوشمندانه

از dir() برای دیدن همه‌ی توابع و متغیرهای یه ماژول استفاده کن:

import math
print(dir(math))  # همه چیزهای موجود در math رو نشون میده

از help() برای دیدن مستندات:

help(math.sqrt)  # مستندات تابع sqrt

✍️ تمرین‌ها

تمرین ۱ (ساده): با import math سینوس ۳۰ درجه رو حساب کن. (راهنمایی: math.radians() و math.sin())

تمرین ۲ (متوسط): با random یه عدد تصادفی بین ۱ تا ۱۰۰ تولید کن و به کاربر بگو حدس بزنه.

تمرین ۳ (چالش‌برانگیز): یک ماژول به اسم عملیات بساز که شامل توابع جمع، تفریق، ضرب و تقسیم باشه. سپس ازش در برنامه اصلی استفاده کن.
