📦 درس ۳: متغیرها

سطح: مبتدی | زمان مطالعه: ۱۵ دقیقه

🎯 هدف این درس

توی این درس یاد می‌گیری که چطور اطلاعات رو توی جعبه‌هایی به اسم متغیر ذخیره کنی و بعداً ازشون استفاده کنی.

📖 متغیر چیست؟

متغیر مثل یه جعبه یا ظرف هست که می‌تونی هر چیزی رو توش بذاری و بعداً دوباره ازش بیرون بیاری.

فرض کن می‌خوای سن خودت رو توی برنامه ذخیره کنی. به‌جای اینکه هر بار عدد رو بنویسی، می‌تونی توی یه متغیر بذاری و هرجا نیاز شد ازش استفاده کنی.

💡 یادت باشه: متغیرها مثل برچسب‌هایی روی جعبه‌ها هستن. هر جعبه یه اسم داره که باهاش می‌تونی بهش دسترسی پیدا کنی.

💻 تعریف متغیر

برای تعریف یه متغیر، فقط کافیه یه اسم انتخاب کنی و با علامت = یه مقدار بهش بدی:

سن = 25
نام = "علی"
قد = 175.5

حالا می‌تونی این متغیرها رو توی print() استفاده کنی:

print(سن)
print(نام)
print(قد)
خروجی: 
25
علی
175.5

💻 قوانین نام‌گذاری متغیرها

  • اسم متغیر می‌تونه از حروف انگلیسی، اعداد و _ (زیرخط) تشکیل بشه.
  • اسم متغیر نمی‌تونه با عدد شروع بشه.
  • اسم متغیر به حروف بزرگ و کوچک حساسه (سن با SEN فرق داره).
  • از کلمات کلیدی پایتون مثل if، for، while و ... نمی‌تونی استفاده کنی.

اسم‌های درست:

سن = 30
نام_کاربر = "علی"
علی_رضایی = 20
num1 = 10

اسم‌های غلط:

1num = 10  # اشتباه! با عدد شروع شده
نام-کاربر = "علی"  # اشتباه! خط فاصله مجاز نیست
if = 5  # اشتباه! کلمه کلیدی

💻 تغییر مقدار متغیر

می‌تونی هر زمان که خواستی مقدار یه متغیر رو عوض کنی:

سن = 25
print(سن)

سن = 30  # تغییر مقدار
print(سن)

سن = سن + 5  # مقدار قبلی رو +۵ می‌کنه
print(سن)
خروجی: 
25
30
35

💻 متغیرهای چندگانه در یک خط

می‌تونی چند متغیر رو توی یه خط تعریف کنی:

x, y, z = 10, 20, 30
print(x, y, z)
خروجی: 
10 20 30

یا حتی به همه‌شون یه مقدار یکسان بدی:

a = b = c = 100
print(a, b, c)
خروجی: 
100 100 100

💻 استفاده از متغیرها در کنار هم

می‌تونی متغیرها رو با هم ترکیب کنی و توی print() چاپ کنی:

نام = "علی"
سن = 25
print("نام من", نام, "و سن من", سن, "سال است")
خروجی: 
نام من علی و سن من 25 سال است

🧠 اشتباهات رایج

❌ اشتباه: استفاده از متغیر بدون تعریف کردنش: print(سن) وقتی سن تعریف نشده.

✅ راه‌حل: قبل از استفاده، متغیر رو تعریف کن: سن = 25

❌ اشتباه: نوشتن اسم متغیر با فاصله: نام کاربر = "علی"

✅ راه‌حل: از زیرخط استفاده کن: نام_کاربر = "علی"

💡 نکته‌ی هوشمندانه

توی پایتون، برای جابجا کردن دو متغیر، نیازی به متغیر کمکی نیست:

a = 10
b = 20
a, b = b, a  # جابجایی
print(a, b)  # خروجی: 20 10

✍️ تمرین‌ها

تمرین ۱ (ساده): سه متغیر به اسم‌های اسم، سن و شهر تعریف کن و مقادیر دلخواه بهشون بده. بعد همه رو با print() چاپ کن.

تمرین ۲ (متوسط): دو متغیر عدد۱ و عدد۲ تعریف کن و به‌ترتیب ۱۰ و ۲۰ رو بهشون بده. مجموعشون رو توی یه متغیر جدید به اسم جمع بریز و چاپ کن.

تمرین ۳ (چالش‌برانگیز): متغیر سن رو تعریف کن و مقدار ۳۰ بهش بده. بعد توی یه خط جدید، سن رو +۵ کن و دوباره چاپ کن. (راهنمایی: سن = سن + 5)
