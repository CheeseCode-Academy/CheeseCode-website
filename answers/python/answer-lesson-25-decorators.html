📝 پاسخ تمرین ۱

سوال: دکوریتوری بساز که قبل از هر تابع "شروع..." و بعدش "پایان..." چاپ کنه.

✅ پاسخ:

def شروع_پایان(func):
    def wrapper(*args, **kwargs):
        print("شروع...")
        نتیجه = func(*args, **kwargs)
        print("پایان...")
        return نتیجه
    return wrapper

@شروع_پایان
def سلام(نام):
    print(f"سلام {نام}!")

سلام("علی")
خروجی: 
شروع...
سلام علی!
پایان...

📝 پاسخ تمرین ۲

سوال: دکوریتوری بساز که خطاهای تابع رو بگیره و چاپ کنه.

✅ پاسخ:

def خطا_گیر(func):
    def wrapper(*args, **kwargs):
        try:
            return func(*args, **kwargs)
        except Exception as e:
            print(f"خطا در تابع {func.__name__}: {e}")
            return None
    return wrapper

@خطا_گیر
def تقسیم(a, b):
    return a / b

print(تقسیم(10, 2))  # 5.0
print(تقسیم(10, 0))  # خطا
خروجی: 
5.0
خطا در تابع تقسیم: division by zero
None

📝 پاسخ تمرین ۳

سوال: دکوریتوری بساز که زمان اجرای تابع رو اندازه بگیره و گزارش بده.

✅ پاسخ:

import time

def زمان_سنج(func):
    def wrapper(*args, **kwargs):
        شروع = time.time()
        نتیجه = func(*args, **kwargs)
        پایان = time.time()
        print(f"تابع {func.__name__}: {پایان - شروع:.6f} ثانیه")
        return نتیجه
    return wrapper

@زمان_سنج
def حلقه_بزرگ():
    مجموع = 0
    for i in range(1000000):
        مجموع += i ** 2
    return مجموع

حلقه_بزرگ()
خروجی (نمونه): 
تابع حلقه_بزرگ: 0.052341 ثانیه
