پاسخ‌های تشریحی | سطح: مبتدی

📝 پاسخ تمرین ۱

سوال: برنامه‌ای بنویس که از کاربر یک عدد بگیره و بگه که مثبت، منفی یا صفر هست.

✅ پاسخ:

عدد = float(input("یک عدد وارد کنید: "))

if عدد > 0:
    print("عدد مثبت است")
elif عدد < 0:
    print("عدد منفی است")
else:
    print("عدد صفر است")
خروجی (نمونه): 
یک عدد وارد کنید: -5
عدد منفی است

📝 پاسخ تمرین ۲

سوال: برنامه‌ای بنویس که از کاربر سنش رو بپرسه و بر اساس سن، پیام مناسب رو چاپ کنه.

✅ پاسخ:

سن = int(input("سن خود را وارد کنید: "))

if سن < 12:
    print("کودک")
elif سن <= 18:
    print("نوجوان")
elif سن <= 60:
    print("بزرگسال")
else:
    print("سالمند")
خروجی (نمونه): 
سن خود را وارد کنید: 25
بزرگسال

💡 نکته: ترتیب شرط‌ها مهمه. اول کوچکترین محدوده رو چک می‌کنیم و بعد بزرگتر.

📝 پاسخ تمرین ۳

سوال: برنامه‌ای بنویس که سه عدد از کاربر بگیره و بگه که آیا می‌تونن سه ضلع یه مثلث باشن یا نه.

✅ پاسخ:

a = float(input("ضلع اول: "))
b = float(input("ضلع دوم: "))
c = float(input("ضلع سوم: "))

if (a + b > c) and (a + c > b) and (b + c > a):
    print("این سه ضلع می‌توانند یک مثلث بسازند")
else:
    print("این سه ضلع نمی‌توانند یک مثلث بسازند")
خروجی (نمونه): 
ضلع اول: 3
ضلع دوم: 4
ضلع سوم: 5
این سه ضلع می‌توانند یک مثلث بسازند

💡 نکته: شرط مثلث: مجموع هر دو ضلع باید از ضلع سوم بزرگتر باشه.
