📝 پاسخ تمرین ۱

سوال: یک دیکشنری از اطلاعات خودت بساز (نام، سن، شهر، رشته تحصیلی) و چاپ کن.

✅ پاسخ:

من = {
    "نام": "علی رضایی",
    "سن": 25,
    "شهر": "تهران",
    "رشته": "مهندسی کامپیوتر"
}

print(من)
خروجی: 
{'نام': 'علی رضایی', 'سن': 25, 'شهر': 'تهران', 'رشته': 'مهندسی کامپیوتر'}

📝 پاسخ تمرین ۲

سوال: دیکشنری از ۳ نفر با اطلاعات (نام، سن، شهر) بساز و با حلقه همه رو چاپ کن.

✅ پاسخ:

افراد = {
    "علی": {"سن": 25, "شهر": "تهران"},
    "زهرا": {"سن": 30, "شهر": "اصفهان"},
    "رضا": {"سن": 22, "شهر": "شیراز"}
}

for نام, اطلاعات in افراد.items():
    print(f"{نام}: سن {اطلاعات['سن']} سال، اهل {اطلاعات['شهر']}")
خروجی: 
علی: سن 25 سال، اهل تهران
زهرا: سن 30 سال، اهل اصفهان
رضا: سن 22 سال، اهل شیراز

📝 پاسخ تمرین ۳

سوال: برنامه‌ای بنویس که از کاربر اطلاعات افراد رو بگیره و توی دیکشنری ذخیره کنه.

✅ پاسخ:

افراد = {}

while True:
    print("\n1. اضافه کردن فرد جدید")
    print("2. دیدن لیست افراد")
    print("3. خروج")
    
    انتخاب = input("انتخاب خود را وارد کنید: ")
    
    if انتخاب == "1":
        نام = input("نام: ")
        سن = int(input("سن: "))
        شهر = input("شهر: ")
        افراد[نام] = {"سن": سن, "شهر": شهر}
        print(f"{نام} با موفقیت اضافه شد!")
        
    elif انتخاب == "2":
        if not افراد:
            print("هیچ فردی ثبت نشده است!")
        else:
            for نام, اطلاعات in افراد.items():
                print(f"{نام}: {اطلاعات['سن']} سال، {اطلاعات['شهر']}")
                
    elif انتخاب == "3":
        print("خروج از برنامه")
        break
        
    else:
        print("انتخاب نامعتبر!")
خروجی (نمونه): 
1. اضافه کردن فرد جدید
2. دیدن لیست افراد
3. خروج
