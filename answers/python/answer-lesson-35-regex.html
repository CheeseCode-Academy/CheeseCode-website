✅ پاسخ تمرین‌های درس ۳۵: عبارت‌های منظم

پاسخ‌های تشریحی | سطح: پیشرفته

📝 پاسخ تمرین ۱

سوال: با regex تمام اعداد یک متن رو پیدا کن.

✅ پاسخ:

import re

متن = "من 25 سال دارم و 3 تا کتاب خوندم. قیمت 1500 تومان بود."
اعداد = re.findall(r"\d+", متن)
print(f"اعداد: {اعداد}")
خروجی: 
اعداد: ['25', '3', '1500']

📝 پاسخ تمرین ۲

سوال: با regex کدهای پستی (۵ رقمی) رو از متن استخراج کن.

✅ پاسخ:

import re

متن = "کد پستی: 12345 و 67890 و 123456 و 5432"
کدها = re.findall(r"\b\d{5}\b", متن)
print(f"کدهای پستی: {کدها}")
خروجی: 
کدهای پستی: ['12345', '67890']

💡 نکته: \b برای تطابق با مرز کلمه استفاده میشه تا اعداد ۶ رقمی یا ۴ رقمی پیدا نشن.

📝 پاسخ تمرین ۳

سوال: با regex یک اعتبارسنجی کامل برای شماره تلفن همراه (شروع با ۰۹ و ۱۱ رقم) بنویس.

✅ پاسخ:

import re

def اعتبارسنجی_تلفن(تلفن):
    # ۰۹۱۲۳۴۵۶۷۸۹
    الگو = r"^09\d{9}$"
    return bool(re.match(الگو, تلفن))

# تست
تلفن‌ها = [
    "09123456789",   # درست
    "0912",          # غلط
    "0912345678",    # غلط (۱۰ رقم)
    "091234567890",  # غلط (۱۲ رقم)
    "02112345678",   # غلط (شروع با ۰۲)
    "0912-345-6789", # غلط (خط تیره)
]

for تلفن in تلفن‌ها:
    print(f"{تلفن}: {اعتبارسنجی_تلفن(تلفن)}")
خروجی: 
09123456789: True
0912: False
0912345678: False
091234567890: False
02112345678: False
0912-345-6789: False
