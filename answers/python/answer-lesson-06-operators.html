📝 پاسخ تمرین ۱

سوال: برنامه‌ای بنویس که دو عدد از کاربر بگیره و مجموع، تفریق، ضرب و تقسیمشون رو چاپ کنه.

✅ پاسخ:

a = float(input("عدد اول را وارد کنید: "))
b = float(input("عدد دوم را وارد کنید: "))

print("مجموع:", a + b)
print("تفریق:", a - b)
print("ضرب:", a * b)
print("تقسیم:", a / b)
خروجی (نمونه): 
عدد اول را وارد کنید: 10
عدد دوم را وارد کنید: 3
مجموع: 13.0
تفریق: 7.0
ضرب: 30.0
تقسیم: 3.3333333333333335

💡 نکته: از float() استفاده کردیم تا بشه با اعداد اعشاری هم کار کرد.

📝 پاسخ تمرین ۲

سوال: برنامه‌ای بنویس که از کاربر یک عدد بگیره و بگه زوجه یا فرد؟

✅ پاسخ:

عدد = int(input("یک عدد وارد کنید: "))

if عدد % 2 == 0:
    print("عدد زوج است")
else:
    print("عدد فرد است")
خروجی (نمونه): 
یک عدد وارد کنید: 7
عدد فرد است

💡 نکته: اگر باقیمانده تقسیم بر ۲ برابر ۰ باشه، عدد زوجه.

📝 پاسخ تمرین ۳

سوال: برنامه‌ای بنویس که سه عدد از کاربر بگیره و بزرگترینشون رو پیدا کنه و چاپ کنه.

✅ پاسخ:

a = float(input("عدد اول: "))
b = float(input("عدد دوم: "))
c = float(input("عدد سوم: "))

بزرگترین = a
if b > بزرگترین:
    بزرگترین = b
if c > بزرگترین:
    بزرگترین = c

print("بزرگترین عدد:", بزرگترین)
خروجی (نمونه): 
عدد اول: 15
عدد دوم: 8
عدد سوم: 22
بزرگترین عدد: 22.0

💡 نکته: اول a رو بزرگترین فرض می‌کنیم، بعد با b و c مقایسه می‌کنیم و اگر بزرگتر بودن جایگزینشون می‌کنیم.
