📝 پاسخ تمرین ۱

سوال: سه کلاس با متد صدا_بده بساز و با یک حلقه همه رو صدا بزن.

✅ پاسخ:

class سگ:
    def صدا_بده(self):
        return "هاپ هاپ!"

class گربه:
    def صدا_بده(self):
        return "میو میو!"

class پرنده:
    def صدا_بده(self):
        return "جیک جیک!"

حیوانات = [سگ(), گربه(), پرنده()]
for حیوان in حیوانات:
    print(حیوان.صدا_بده())
خروجی: 
هاپ هاپ!
میو میو!
جیک جیک!

📝 پاسخ تمرین ۲

سوال: کلاس وسیله_نقلیه بساز و کلاس‌های ماشین و دوچرخه ازش ارث ببرن و متد حرکت_کن رو بازنویسی کنن.

✅ پاسخ:

class وسیله_نقلیه:
    def حرکت_کن(self):
        return "وسیله نقلیه در حال حرکت"

class ماشین(وسیله_نقلیه):
    def حرکت_کن(self):
        return "ماشین با بنزین حرکت می‌کند"

class دوچرخه(وسیله_نقلیه):
    def حرکت_کن(self):
        return "دوچرخه با پدال حرکت می‌کند"

وسایل = [ماشین(), دوچرخه()]
for وسیله in وسایل:
    print(وسیله.حرکت_کن())
خروجی: 
ماشین با بنزین حرکت می‌کند
دوچرخه با پدال حرکت می‌کند

📝 پاسخ تمرین ۳

سوال: کلاس انتزاعی محاسبه_گر بساز با متد محاسبه و دو کلاس جمع_کننده و ضرب_کننده که اون رو پیاده‌سازی کنن.

✅ پاسخ:

from abc import ABC, abstractmethod

class محاسبه_گر(ABC):
    @abstractmethod
    def محاسبه(self, a, b):
        pass

class جمع_کننده(محاسبه_گر):
    def محاسبه(self, a, b):
        return a + b

class ضرب_کننده(محاسبه_گر):
    def محاسبه(self, a, b):
        return a * b

class تفریق_کننده(محاسبه_گر):
    def محاسبه(self, a, b):
        return a - b

عملیات‌ها = [جمع_کننده(), ضرب_کننده(), تفریق_کننده()]
for عملیات in عملیات‌ها:
    print(عملیات.محاسبه(10, 5))
خروجی: 
15
50
5
