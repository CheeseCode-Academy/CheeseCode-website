پاسخ‌های تشریحی | سطح: مبتدی

📝 پاسخ تمرین ۱

سوال: با while اعداد ۱ تا ۱۰ رو چاپ کن.

✅ پاسخ:

i = 1

while i <= 10:
    print(i)
    i += 1

📝 پاسخ تمرین ۲

سوال: برنامه‌ای بنویس که از کاربر عددی بگیره و با while تمام اعداد از ۱ تا اون عدد رو چاپ کنه.

✅ پاسخ:

n = int(input("یک عدد وارد کنید: "))
i = 1

while i <= n:
    print(i)
    i += 1

📝 پاسخ تمرین ۳

سوال: برنامه‌ای بنویس که از کاربر عددی بگیره و فاکتوریل اون عدد رو با while محاسبه کنه.

✅ پاسخ:

n = int(input("یک عدد وارد کنید: "))
فاکتوریل = 1
i = 1

while i <= n:
    فاکتوریل *= i  # یعنی فاکتوریل = فاکتوریل * i
    i += 1

print("فاکتوریل", n, "برابر است با:", فاکتوریل)
خروجی (نمونه): 
یک عدد وارد کنید: 5
فاکتوریل 5 برابر است با: 120

💡 نکته: فاکتوریل ۵ = ۱×۲×۳×۴×۵ = ۱۲۰
