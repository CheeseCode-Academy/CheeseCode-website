📝 پاسخ تمرین ۱

سوال: پایتون رو روی کامپیوترت نصب کن و با دستور python --version نسخه‌اش رو چک کن.

✅ پاسخ:

برای نصب پایتون، مراحل زیر رو انجام بده:

  1. به سایت python.org برو.
  2. روی دکمه‌ی زرد Download Python کلیک کن.
  3. فایل نصب رو اجرا کن و حتماً تیک "Add Python to PATH" رو بزن.
  4. روی Install Now کلیک کن و صبر کن تا نصب تموم بشه.
  5. خط فرمان (CMD) رو باز کن و python --version رو تایپ کن.

خروجی باید چیزی شبیه این باشه:

خروجی نمونه: 
Python 3.14.0

📝 پاسخ تمرین ۲

سوال: توی محیط تعاملی پایتون، سه چیز مختلف رو با print چاپ کن. مثلاً اسم خودت، اسم شهرت و غذای مورد علاقت.

✅ پاسخ:

اول خط فرمان رو باز کن و python رو تایپ کن تا وارد محیط تعاملی بشی. سپس این کدها رو به ترتیب تایپ کن:

print("علی رضایی")
print("تهران")
print("پیتزا")
خروجی: 
علی رضایی
تهران
پیتزا

💡 نکته: تو می‌تونی هر متنی که دوست داری رو داخل " " قرار بدی و چاپ کنی.

📝 پاسخ تمرین ۳

سوال: توی خط فرمان (CMD)، بدون اینکه وارد محیط پایتون بشی، با دستور python -c "print('سلام')" مستقیم کد رو اجرا کن.

✅ پاسخ:

خط فرمان (CMD) رو باز کن و دقیقاً این دستور رو تایپ کن:

python -c "print('سلام')"
خروجی: 
سلام

💡 نکته: این روش برای اجرای سریع کدهای کوتاه خیلی مفیده. نیازی نیست وارد محیط پایتون بشی و مستقیم نتیجه رو می‌بینی.
