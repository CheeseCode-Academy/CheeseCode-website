📝 پاسخ تمرین ۱

سوال: برنامه‌ای بنویس که از کاربر یک عدد بگیره و تقسیم ۱۰۰ بر اون رو انجام بده. خطای تقسیم بر صفر رو مدیریت کن.

✅ پاسخ:

try:
    عدد = float(input("یک عدد وارد کنید: "))
    نتیجه = 100 / عدد
    print(f"۱۰۰ تقسیم بر {عدد} برابر است با: {نتیجه}")
except ZeroDivisionError:
    print("خطا: تقسیم بر صفر ممکن نیست!")
except ValueError:
    print("خطا: لطفاً یک عدد معتبر وارد کنید!")
خروجی (نمونه): 
یک عدد وارد کنید: 0
خطا: تقسیم بر صفر ممکن نیست!

📝 پاسخ تمرین ۲

سوال: برنامه‌ای بنویس که از کاربر یه فایل بخونه و محتواش رو چاپ کنه. خطای FileNotFoundError رو مدیریت کن.

✅ پاسخ:

نام_فایل = input("نام فایل را وارد کنید: ")

try:
    with open(نام_فایل, "r") as فایل:
        محتوا = فایل.read()
        print("محتوای فایل:")
        print(محتوا)
except FileNotFoundError:
    print(f"خطا: فایل '{نام_فایل}' پیدا نشد!")
except Exception as e:
    print(f"خطای ناشناخته: {e}")
خروجی (نمونه): 
نام فایل را وارد کنید: nonexistent.txt
خطا: فایل 'nonexistent.txt' پیدا نشد!

📝 پاسخ تمرین ۳

سوال: تابعی بنویس که سن رو بگیره و اگر منفی یا بزرگتر از ۱۲۰ بود، خطا پرتاب کنه.

✅ پاسخ:

def بررسی_سن(سن):
    if سن < 0:
        raise ValueError("سن نمی‌تواند منفی باشد!")
    elif سن > 120:
        raise ValueError("سن نمی‌تواند بیشتر از ۱۲۰ باشد!")
    return "سن معتبر است"

try:
    سن = int(input("سن خود را وارد کنید: "))
    print(بررسی_سن(سن))
except ValueError as e:
    print(f"خطا: {e}")
خروجی (نمونه ۱): 
سن خود را وارد کنید: 25
سن معتبر است
خروجی (نمونه ۲): 
سن خود را وارد کنید: -5
خطا: سن نمی‌تواند منفی باشد!
