✅ پاسخ تمرین‌های درس ۲۱: کار با فایل‌ها

پاسخ‌های تشریحی | سطح: متوسط

📝 پاسخ تمرین ۱

سوال: یه فایل به اسم name.txt بساز و اسم خودت رو توش بنویس.

✅ پاسخ:

with open("name.txt", "w") as فایل:
    فایل.write("علی رضایی")

📝 پاسخ تمرین ۲

سوال: فایل name.txt رو بخون و محتواش رو چاپ کن.

✅ پاسخ:

with open("name.txt", "r") as فایل:
    محتوا = فایل.read()
    print("محتوای فایل:", محتوا)
خروجی: 
محتوای فایل: علی رضایی

📝 پاسخ تمرین ۳

سوال: برنامه‌ای بنویس که از کاربر ۵ اسم بگیره، توی فایل names.txt ذخیره کنه و بعد دوباره بخونه و چاپ کنه.

✅ پاسخ:

# گرفتن اسامی
اسامی = []
for i in range(5):
    نام = input(f"اسم {i+1} را وارد کنید: ")
    اسامی.append(نام)

# ذخیره در فایل
with open("names.txt", "w") as فایل:
    for نام in اسامی:
        فایل.write(نام + "\n")

print("اسامی ذخیره شدند!")

# خواندن از فایل
print("\nاسامی ذخیره شده:")
with open("names.txt", "r") as فایل:
    for خط in فایل:
        print("-", خط.strip())
خروجی (نمونه):

اسم 3 را وارد کنید: رضا
اسم 4 را وارد کنید: سارا
اسم 5 را وارد کنید: محمد
اسامی ذخیره شدند!
