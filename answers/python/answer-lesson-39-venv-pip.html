✅ پاسخ تمرین‌های درس ۳۹: محیط مجازی و pip

پاسخ‌های تشریحی | سطح: پیشرفته

📝 پاسخ تمرین ۱

سوال: یک محیط مجازی جدید بساز و یک پکیج توش نصب کن.

✅ پاسخ:

در خط فرمان:

# ایجاد محیط
python -m venv testenv

# فعال‌سازی (ویندوز)
testenv\Scripts\activate

# فعال‌سازی (لینوکس/Mac)
source testenv/bin/activate

# نصب پکیج
pip install requests

# بررسی
pip list

# غیرفعال‌سازی
deactivate

📝 پاسخ تمرین ۲

سوال: یک requirements.txt برای پروژه‌ای که ۳ پکیج داره بساز.

✅ پاسخ:

ابتدا پکیج‌ها رو نصب کن:

pip install requests numpy pandas

سپس فایل requirements.txt رو ایجاد کن:

# در خط فرمان:
pip freeze > requirements.txt

# محتوای فایل:
# requests==2.28.0
# numpy==1.24.0
# pandas==1.5.0

📝 پاسخ تمرین ۳

سوال: یک پکیج ساده با دو تابع بساز و در محیط مجازی نصب کن.

✅ پاسخ:

ساختار پکیج:

myutils/
├── myutils/
│   ├── __init__.py
│   └── utils.py
└── setup.py

myutils/utils.py:

def سلام(نام):
    return f"سلام {نام}!"

def جمع(a, b):
    return a + b

def ضرب(a, b):
    return a * b

myutils/__init__.py:

from .utils import سلام, جمع, ضرب

setup.py:

from setuptools import setup, find_packages

setup(
    name="myutils",
    version="1.0.0",
    packages=find_packages(),
    author="Your Name",
    description="A simple utility package",
)

نصب و استفاده:

# در محیط مجازی:
pip install -e .

# تست:
python -c "from myutils import سلام; print(سلام('علی'))"
