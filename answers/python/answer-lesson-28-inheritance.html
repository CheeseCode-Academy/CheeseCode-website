📝 پاسخ تمرین ۱

سوال: کلاس شکل بساز و کلاس‌های مستطیل و دایره ازش ارث ببرن.

✅ پاسخ:

class شکل:
    def مساحت(self):
        return 0
    
    def محیط(self):
        return 0

class مستطیل(شکل):
    def __init__(self, طول, عرض):
        self.طول = طول
        self.عرض = عرض
    
    def مساحت(self):
        return self.طول * self.عرض
    
    def محیط(self):
        return 2 * (self.طول + self.عرض)

class دایره(شکل):
    def __init__(self, شعاع):
        self.شعاع = شعاع
        from math import pi
    
    def مساحت(self):
        return 3.14 * self.شعاع ** 2
    
    def محیط(self):
        return 2 * 3.14 * self.شعاع

م = مستطیل(5, 3)
د = دایره(4)

print(f"مساحت مستطیل: {م.مساحت()}")  # 15
print(f"محیط مستطیل: {م.محیط()}")    # 16
print(f"مساحت دایره: {د.مساحت():.2f}")  # 50.24
خروجی: 
مساحت مستطیل: 15
محیط مستطیل: 16
مساحت دایره: 50.24

📝 پاسخ تمرین ۲

سوال: کلاس کارمند و مدیر بساز که مدیر از کارمند ارث ببره و حقوق بیشتری داشته باشه.

✅ پاسخ:

class کارمند:
    def __init__(self, نام, حقوق_پایه):
        self.نام = نام
        self.حقوق_پایه = حقوق_پایه
    
    def حقوق(self):
        return self.حقوق_پایه

class مدیر(کارمند):
    def __init__(self, نام, حقوق_پایه, پاداش):
        super().__init__(نام, حقوق_پایه)
        self.پاداش = پاداش
    
    def حقوق(self):
        return super().حقوق() + self.پاداش

کارمند_ساده = کارمند("علی", 1000)
مدیر_شرکت = مدیر("زهرا", 1000, 500)

print(f"حقوق کارمند: {کارمند_ساده.حقوق()}")
print(f"حقوق مدیر: {مدیر_شرکت.حقوق()}")
خروجی: 
حقوق کارمند: 1000
حقوق مدیر: 1500

📝 پاسخ تمرین ۳

سوال: با وراثت چندگانه، کلاس پرنده_شناگر بساز که هم پرواز کنه هم شنا.

✅ پاسخ:

class پرنده:
    def پرواز_کن(self):
        return "پرنده در حال پرواز"

class شناگر:
    def شنا_کن(self):
        return "شناگر در حال شنا"

class پرنده_شناگر(پرنده, شناگر):
    def نام_بگو(self, نام):
        return f"{نام} یک پرنده شناگر است!"

مرغ_دریا = پرنده_شناگر()
print(مرغ_دریا.پرواز_کن())
print(مرغ_دریا.شنا_کن())
print(مرغ_دریا.نام_بگو("پلیکان"))
خروجی: 
پرنده در حال پرواز
شناگر در حال شنا
پلیکان یک پرنده شناگر است!
