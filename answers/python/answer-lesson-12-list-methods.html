✅ پاسخ تمرین‌های درس ۱۲: متدهای لیست

پاسخ‌های تشریحی | سطح: مبتدی

📝 پاسخ تمرین ۱

سوال: لیستی از اعداد بساز و با sort() مرتبش کن.

✅ پاسخ:

اعداد = [15, 3, 8, 22, 1, 9]
اعداد.sort()
print(اعداد)
خروجی: 
[1, 3, 8, 9, 15, 22]

📝 پاسخ تمرین ۲

سوال: لیستی از اعداد بساز و با reverse() برعکسش کن.

✅ پاسخ:

اعداد = [1, 2, 3, 4, 5]
اعداد.reverse()
print(اعداد)
خروجی: 
[5, 4, 3, 2, 1]

📝 پاسخ تمرین ۳

سوال: برنامه‌ای بنویس که از کاربر ۱۰ عدد بگیره، توی لیست ذخیره کنه و سپس لیست رو مرتب کنه، بزرگترین و کوچکترین رو پیدا کنه، تعداد اعداد زوج رو بشماره.

✅ پاسخ:

اعداد = []

for i in range(10):
    عدد = int(input(f"عدد {i+1} را وارد کنید: "))
    اعداد.append(عدد)

# مرتب‌سازی
اعداد.sort()

# بزرگترین و کوچکترین
بزرگترین = max(اعداد)
کوچکترین = min(اعداد)

# تعداد زوج‌ها
تعداد_زوج = 0
for عدد in اعداد:
    if عدد % 2 == 0:
        تعداد_زوج += 1

print("لیست مرتب:", اعداد)
print("بزرگترین:", بزرگترین)
print("کوچکترین:", کوچکترین)
print("تعداد اعداد زوج:", تعداد_زوج)
خروجی (نمونه): 
عدد 1 را وارد کنید: 15
عدد 2 را وارد کنید: 8

عدد 6 را وارد کنید: 7
عدد 7 را وارد کنید: 18
عدد 8 را وارد کنید: 5
عدد 9 را وارد کنید: 10
