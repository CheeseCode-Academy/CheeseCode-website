📝 پاسخ تمرین ۱

سوال: کلاسی با یه متد کلاس بساز که یه پیام چاپ کنه.

✅ پاسخ:

class پیام:
    @classmethod
    def سلام(cls):
        print("سلام از متد کلاس!")

پیام.سلام()
خروجی: 
سلام از متد کلاس!

📝 پاسخ تمرین ۲

سوال: کلاس تبدیل بساز با متدهای استاتیک برای تبدیل دما.

✅ پاسخ:

class تبدیل:
    @staticmethod
    def سلسیوس_به_فارنهایت(c):
        return (c * 9/5) + 32
    
    @staticmethod
    def فارنهایت_به_سلسیوس(f):
        return (f - 32) * 5/9

print(f"۲۵°C = {تبدیل.سلسیوس_به_فارنهایت(25):.1f}°F")
print(f"۷۷°F = {تبدیل.فارنهایت_به_سلسیوس(77):.1f}°C")
خروجی: 
25°C = 77.0°F
77°F = 25.0°C

📝 پاسخ تمرین ۳

سوال: کلاس کارخانه بساز که با متد کلاس، اشیاء مختلف تولید کنه.

✅ پاسخ:

class محصول:
    def __init__(self, نام, قیمت):
        self.نام = نام
        self.قیمت = قیمت
    
    def __str__(self):
        return f"{self.نام} - {self.قیمت} تومان"

class کارخانه:
    @classmethod
    def تولید_لپتاپ(cls):
        return محصول("لپ‌تاپ", 15000000)
    
    @classmethod
    def تولید_موبایل(cls):
        return محصول("موبایل", 8000000)
    
    @classmethod
    def تولید_تبلت(cls):
        return محصول("تبلت", 5000000)

محصولات = [
    کارخانه.تولید_لپتاپ(),
    کارخانه.تولید_موبایل(),
    کارخانه.تولید_تبلت()
]

for محصول in محصولات:
    print(محصول)
خروجی: 
لپ‌تاپ - 15000000 تومان
موبایل - 8000000 تومان
تبلت - 5000000 تومان
