📝 پاسخ تمرین ۱

سوال: تابعی بنویس که دو عدد بگیره و حاصل ضربشون رو برگردونه.

✅ پاسخ:

def ضرب(a, b):
    return a * b

print(ضرب(5, 4))
print(ضرب(10, 10))
خروجی: 
20
100

📝 پاسخ تمرین ۲

سوال: تابعی بنویس که یک لیست از اعداد بگیره و مجموع و میانگین رو به صورت دیکشنری برگردونه.

✅ پاسخ:

def آمار(لیست):
    مجموع = sum(لیست)
    تعداد = len(لیست)
    میانگین = مجموع / تعداد
    return {"مجموع": مجموع, "میانگین": میانگین}

اعداد = [10, 20, 30, 40, 50]
نتیجه = آمار(اعداد)
print("مجموع:", نتیجه["مجموع"])
print("میانگین:", نتیجه["میانگین"])
خروجی: 
مجموع: 150
میانگین: 30.0

📝 پاسخ تمرین ۳

سوال: تابعی بنویس که با *args هر تعداد عدد بگیره و بزرگترینشون رو پیدا کنه.

✅ پاسخ:

def بزرگترین(*اعداد):
    if not اعداد:  # اگر عددی نبود
        return None
    بزرگ = اعداد[0]
    for عدد in اعداد:
        if عدد > بزرگ:
            بزرگ = عدد
    return بزرگ

print(بزرگترین(10, 20, 5, 30, 15))
print(بزرگترین(1, 2, 3))
print(بزرگترین())
خروجی: 
30
3
None

💡 نکته: می‌تونی از تابع max() هم استفاده کنی: return max(اعداد) if اعداد else None
