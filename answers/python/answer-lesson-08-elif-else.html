📝 پاسخ تمرین ۱

سوال: برنامه‌ای بنویس که از کاربر یک عدد بگیره و بگه که "کوچک"، "متوسط" یا "بزرگ" هست.

✅ پاسخ:

عدد = float(input("یک عدد وارد کنید: "))

if عدد < 10:
    print("کوچک")
elif 10 <= عدد <= 50:
    print("متوسط")
else:
    print("بزرگ")

یک عدد وارد کنید: 35
متوسط

📝 پاسخ تمرین ۲

سوال: برنامه‌ای بنویس که از کاربر سه عدد بگیره و اون‌ها رو به ترتیب صعودی مرتب کنه و چاپ کنه.

✅ پاسخ:

a = float(input("عدد اول: "))
b = float(input("عدد دوم: "))
c = float(input("عدد سوم: "))

if a <= b <= c:
    print(a, b, c)
elif a <= c <= b:
    print(a, c, b)
elif b <= a <= c:
    print(b, a, c)
elif b <= c <= a:
    print(b, c, a)
elif c <= a <= b:
    print(c, a, b)
else:
    print(c, b, a)
خروجی (نمونه): 
عدد اول: 15
عدد دوم: 8
عدد سوم: 22
8.0 15.0 22.0

💡 نکته: این روش ساده‌ترین راه برای مرتب کردن سه عدد هست، ولی برای تعداد بیشتر از روش‌های پیشرفته‌تر استفاده می‌کنیم.

📝 پاسخ تمرین ۳

سوال: برنامه‌ای بنویس که از کاربر یک عدد بگیره و بگه که آیا عدد اول هست یا نه.

✅ پاسخ:

عدد = int(input("یک عدد وارد کنید: "))

if عدد <= 1:
    print("عدد اول نیست")
elif عدد == 2:
    print("عدد اول است")
else:
    اول = True
    for i in range(2, int(عدد ** 0.5) + 1):
        if عدد % i == 0:
            اول = False
            break
    
    if اول:
        print("عدد اول است")
    else:
        print("عدد اول نیست")
خروجی (نمونه): 
یک عدد وارد کنید: 17
عدد اول است

💡 نکته: این تمرین از حلقه for استفاده میکنه که توی درس‌های بعدی یاد می‌گیری. فعلاً فقط با مفهومش آشنا شو.
