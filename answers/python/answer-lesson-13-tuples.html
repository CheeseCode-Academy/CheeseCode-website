✅ پاسخ تمرین‌های درس ۱۳: تاپل‌ها

پاسخ‌های تشریحی | سطح: مبتدی

📝 پاسخ تمرین ۱

سوال: یک تاپل از ۵ شهر favorite خودت بساز و با حلقه for چاپ کن.

✅ پاسخ:

شهرها = ("تهران", "اصفهان", "شیراز", "مشهد", "تبریز")

for شهر in شهرها:
    print(شهر)
خروجی: 
تهران
اصفهان
شیراز
مشهد
تبریز

📝 پاسخ تمرین ۲

سوال: یک تاپل از ۳ رنگ بساز و با unpacking هر کدوم رو توی متغیر جداگانه بریز.

✅ پاسخ:

رنگ‌ها = ("قرمز", "آبی", "سبز")
رنگ۱, رنگ۲, رنگ۳ = رنگ‌ها

print("رنگ اول:", رنگ۱)
print("رنگ دوم:", رنگ۲)
print("رنگ سوم:", رنگ۳)
خروجی: 
رنگ اول: قرمز
رنگ دوم: آبی
رنگ سوم: سبز

📝 پاسخ تمرین ۳

سوال: یک تاپل از اعداد بساز و جمع همه‌شون رو بدون استفاده از sum() محاسبه کن.

✅ پاسخ:

اعداد = (10, 20, 30, 40, 50)
جمع = 0

for عدد in اعداد:
    جمع += عدد

print("مجموع اعداد:", جمع)
خروجی: 
مجموع اعداد: 150

💡 نکته: البته می‌تونی از sum(اعداد) هم استفاده کنی! اینجا فقط برای تمرین از حلقه استفاده کردیم.
