📝 پاسخ تمرین ۱

سوال: تابعی بنویس که نام و سن رو بگیره، با سن پیش‌فرض ۱۸.

✅ پاسخ:

def معرفی(نام, سن=18):
    print(f"سلام! من {نام} هستم و {سن} سال دارم.")

معرفی("علی")        # سن پیش‌فرض ۱۸
معرفی("زهرا", 25)  # سن ۲۵
خروجی: 
سلام! من علی هستم و 18 سال دارم.
سلام! من زهرا هستم و 25 سال دارم.

📝 پاسخ تمرین ۲

سوال: تابعی بنویس که متن و تعداد تکرار رو بگیره و متن رو به تعداد مشخص چاپ کنه (تعداد پیش‌فرض ۱).

✅ پاسخ:

def تکرار(متن, تعداد=1):
    for i in range(تعداد):
        print(متن)

تکرار("سلام")
print("---")
تکرار("پایتون", 3)
خروجی: 
سلام
---
پایتون
پایتون
پایتون

📝 پاسخ تمرین ۳

سوال: تابعی بنویس که لیستی از اعداد و یک مقدار پیش‌فرض برای mode داشته باشه که مشخص کنه جمع یا ضرب انجام بده.

✅ پاسخ:

def عملیات(اعداد, mode="جمع"):
    if mode == "جمع":
        return sum(اعداد)
    elif mode == "ضرب":
        نتیجه = 1
        for عدد in اعداد:
            نتیجه *= عدد
        return نتیجه
    else:
        return "mode نامعتبر!"

لیست = [2, 3, 4]
print("جمع:", عملیات(لیست))
print("ضرب:", عملیات(لیست, "ضرب"))
خروجی: 
جمع: 9
ضرب: 24

💡 نکته: با پارامتر mode می‌تونی رفتار تابع رو تغییر بدی بدون اینکه کد جدیدی بنویسی.
