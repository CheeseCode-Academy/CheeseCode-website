📝 پاسخ تمرین ۱

سوال: با import math سینوس ۳۰ درجه رو حساب کن.

✅ پاسخ:

import math

زاویه = 30
رادیان = math.radians(زاویه)
سینوس = math.sin(رادیان)

print(f"سینوس {زاویه} درجه: {سینوس}")
خروجی: 
سینوس 30 درجه: 0.5

💡 نکته: توابع مثلثاتی در math با رادیان کار می‌کنن، برای همین با radians() درجه رو به رادیان تبدیل می‌کنیم.

📝 پاسخ تمرین ۲

سوال: با random یه عدد تصادفی بین ۱ تا ۱۰۰ تولید کن و به کاربر بگو حدس بزنه.

✅ پاسخ:

import random

عدد_مخفی = random.randint(1, 100)
تعداد_حدس = 0

print("یک عدد بین ۱ تا ۱۰۰ حدس بزنید!")

while True:
    حدس = int(input("حدس شما: "))
    تعداد_حدس += 1
    
    if حدس == عدد_مخفی:
        print(f"آفرین! در {تعداد_حدس} بار حدس زدید.")
        break
    elif حدس < عدد_مخفی:
        print("بزرگتر!")
    else:
        print("کوچکتر!")
خروجی (نمونه): 
یک عدد بین ۱ تا ۱۰۰ حدس بزنید!
حدس شما: 50
بزرگتر!
حدس شما: 75
کوچکتر!
حدس شما: 63
آفرین! در 3 بار حدس زدید.

📝 پاسخ تمرین ۳

سوال: یک ماژول به اسم عملیات بساز که شامل توابع جمع، تفریق، ضرب و تقسیم باشه.

✅ پاسخ:

ابتدا فایل عملیات.py رو می‌سازیم:

# فایل: عملیات.py
def جمع(a, b):
    return a + b

def تفریق(a, b):
    return a - b

def ضرب(a, b):
    return a * b

def تقسیم(a, b):
    if b == 0:
        return "خطا: تقسیم بر صفر!"
    return a / b

حالا ازش استفاده می‌کنیم:

import عملیات

print("جمع:", عملیات.جمع(10, 5))
print("تفریق:", عملیات.تفریق(10, 5))
print("ضرب:", عملیات.ضرب(10, 5))
print("تقسیم:", عملیات.تقسیم(10, 5))
print("تقسیم بر صفر:", عملیات.تقسیم(10, 0))
خروجی: 
جمع: 15
تفریق: 5
ضرب: 50
تقسیم: 2.0
تقسیم بر صفر: خطا: تقسیم بر صفر!

💡 نکته: ماژول‌ها بهت کمک می‌کنن کدت رو سازماندهی کنی و ازش در جاهای مختلف استفاده کنی.
